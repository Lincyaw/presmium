# 发布、期数与恢复

本参考用于同一论文系列的期数选择、文案、浏览器上传和中断恢复。目标账号来自工作区约定或用户明确选择；本技能不把别的账号当成授权目标。

## 期数来自账号与已提交记录

制作开始时查看登录账号，再在笔记管理中搜索、分页查看“论文分享第……期”。同时读取本地论文的发布记录，优先用稳定论文标识关联同一篇，而非只比较短标题。

- 兼容“第一期”“第十二期”“第103期”、中英文冒号和空格，按数值比较，不按字符串或卡片顺序取最大值。非本系列笔记不计入。
- 已发布、审核中和有可靠提交回执的本地记录都占用期数；不把浏览器显示的笔记总数当期数，不凭本机仅有的两篇推断账号的全部历史。
- 同一篇已有一期时沿用它并编辑原笔记。远端记录与本地记录冲突、分页未读完或账号不一致时先消除不确定性，不能猜一个号发布。
- 新论文用已占用最大期数加一，写入本篇发布记录。同一账号同一系列串行提交；若其他任务正在占用同一期，先等待或协调，不靠两份本地草稿同时预留解决并发。
- 最终提交前再次核对账号、远端最大期数和本篇是否已经存在。只有其他论文占用了候选号才重排；同一篇的重试保留原号并先查提交结果。期号变动时同步标题及封面上实际出现的期号。
- 账号确实没有该系列且本地也没有已提交记录时从第一期开始。现有论文记录是上下文，不是永久固定的“下一期=三”。

## `publish.md` 的四个区域

第一行是要上传的标题；“简介”下只有公开正文和话题；后两区只供作者和恢复流程使用。新文章采用以下形状，替换尖括号字段，不把模板提示上传：

```markdown
# 论文分享第<中文序号>期：<论文名>

## 简介

今天分享<作者或机构>的论文 <论文名>。

<一段简要介绍：研究什么、如何做、发现什么；保留理解结论必需的条件。>

#文献阅读 #研究生论文 #文献 #带你一起读论文 #大模型 #论文写作

## 发布素材

- [封面](cover.png)
- [动画](dist/<最终文件>.mp4)
- [字幕](dist/<最终字幕>.vtt)
- [视频联系表](dist/<最终联系表>.png)
- [原论文](<规范论文URL>)

## 发布记录

- 论文标识：<arXiv ID（不含版本后缀）或 DOI / 规范 URL>
- 原文版本：<实际版本或未知>
- 账号：<实际核对的账号名；可见的稳定标识如有则保留>
- 期数：<整数>
- 状态：<素材就绪 / 上传中 / 待核实 / 已提交·审核中 / 已发布 / 未通过>
- 素材版本：<本次使用的成片与封面的文件名、大小和 SHA-256>
- 笔记：<提交后核实的 URL 或 ID；尚未获得写“未获得”>
- 最近核实：<时间及工作区时区>
- 回执：[实际页面截图](dist/<截图>.jpg)
```

话题按论文内容选择，以上只是该系列的常用话题。已有文章没有“简介”标题时，先识别第一行标题到第一个作者用素材/记录标题之间的公开正文；不要直接把整份 Markdown 粘贴进编辑器。

简介沿用第一期的简要介绍，不写制作说明、免责声明式段落、配音或素材注释。标题过长时缩短论文名的副标题，保留期数和可辨识的论文名；遵守页面显示的实际长度限制，不凭字符估算认为一定可提交。

## 浏览器操作

1. 读当前浏览器控制工具的说明，用用户指定浏览器或现有已连接浏览器。只操作本次所需页面。进入小红书创作服务平台，核对登录账号和原笔记/候选期数。
2. 新笔记上传最终 MP4；修改已存在的同一篇时优先编辑原笔记，不重新发一条。替换视频用原笔记的“重新上传”，先等现有封面、合集等字段载入，再改动。上传先按工具的文件上传能力操作；隐藏的文件输入框无响应时，改用页面可见的上传入口。若扩展上传要求新增“文件网址”访问权限，优先使用系统原生文件选择器，不擅自扩大扩展权限。原生操作前先核对前台是目标标签页；路径用实际绝对路径，等待“前往文件夹”输入框出现后再填入。
3. 在“编辑封面/设置封面”的自定义图片入口上传 `cover.png`。完整检查当前比例、缩放和裁切后的实际图片：品牌、主题、图和边缘文字均可见。平台默认第一帧、智能推荐或付费 AI 封面都不替代已制作的独立封面。
4. 填最终标题与简介，核对可见输入值、长度和预览。编辑器可能是 contenteditable；使用真实可编辑字段而非带占位文本的空壳。话题按当前 UI 处理，不使用过期元素序号。完整素材链接、来源说明和发布记录不进入公开简介。
5. 工作区已指定或用户已选择系列合集时，核对并复用已有合集；新笔记加入它，替换视频后再核对归属，不另建同名合集。合集名称保存在工作区约定和发布记录中，不把某个账号的名称写成技能全局默认。合成配音按平台实际入口设置“笔记含AI合成内容”等内容类型声明。它是平台字段，和简介中的制作注释是两回事。公开可见、即时发布；其他合集、地点、群聊、原创声明、活动或付费推广只有在相应授权下设置。
6. 具备发布授权后提交；若页面提出验证码、法律协议或新的权限要求，按浏览器工具的确认规则在该具体动作处处理。缺少登录或需用户完成验证时保留页面并明确接手点。不要用脚本绕过。
7. 核实成功回执与笔记管理中的那一条记录，保存可显示标题、封面和状态的截图。替换视频时同时记录提交前显示的新文件名、实际素材哈希及原笔记ID，避免把“打开编辑页”记作替换成功。“已发布”列表可能暂时不显示更新后正在审核的笔记，切到“审核中”或“全部”核实，不据此重新发一条。提交成功且审核中即完成本次上传工作，最终状态照实写入记录。交付笔记链接和实际素材。

每次交互后读取最新状态，只有需要判断裁切或布局时补截图。浏览器自动跳转或新开标签时先查当前标签列表再选择，不因原标签没变化而重复点击。遵守当前控制工具要求的完成摘要与标签保留流程。

## 失败与响应不明

| 观察结果 | 下一步 |
|---|---|
| 音频生成中断 | 读取实际任务与缓存，复用已完成句子，恢复当前缺失部分 |
| 成片版本与简介/封面不一致 | 修正对应素材并重新验收，上传前更新记录的文件版本 |
| 上传尚未结束 | 保留上传页面和记录，观察进度，不创建第二条上传 |
| 点击发布后连接中断或响应丢失 | 标为“待核实”，先看当前页、笔记管理、标题、期数和提交时间；有记录则复用，查不清不重发 |
| 平台明确拒绝且没有生成笔记 | 按明确失败原因修正，再确认账号/期数后重试 |
| 笔记审核中 | 已提交并交付；后续用户要求修改时编辑原笔记 |
| 笔记未通过 | 记录平台原因并修订该篇；不靠换号或重复发同样内容解决 |

本地记录可能过时，截图可能来自旧版本；它们只能帮助恢复，不能替代当前远端状态。保留原笔记 ID 与期数，只有核实没有提交结果后才重新提交。
