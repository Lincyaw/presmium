(intro)=
# Three.js：原子动画合集

Three.js 适合深度本身就是内容的画面：三维空间里的点与向量、曲面、相机的推拉，以及成千上万个粒子。

(clusters)=
## 点云聚类：InstancedMesh 与逐个实例的颜色

(clusters-scene)=
:::{scene} clusters
:durations: 1.2, 2, 1, 1.6
三维空间中的词向量：散开的灰点聚成三团并染色，标出类别，镜头推近其中一团。
:::

三百多个点散在空间里，一次绘制画出全部点。

点按类别聚拢，颜色从灰色过渡到各自类别的颜色。

每一团上方出现类别的名字，是 HTML 标签，跟着三维位置走。

镜头推近“动物”这一团，其他两团缩小变淡。

(descent)=
## 损失曲面与梯度下降：顶点位移、顶点颜色与粗线

(descent-scene)=
:::{scene} descent
:durations: 1.2, 0.8, 2.6, 1.4
一张起伏的损失曲面，小球落在山坡上，沿梯度一步步滚到谷底，身后留下轨迹，镜头推近终点。
:::

平面的每个顶点按损失函数抬高，低处是青色，高处是橙色。

小球落到起点，旁边是此处的损失值。

梯度下降一步一步走向低处，红色轨迹记下走过的路，损失值随之下降。

镜头推近终点，这里是一个局部极小值。

(projection)=
## 向量与投影：ArrowHelper 与虚线

(projection-scene)=
:::{scene} projection
:durations: 1, 1.6, 1.6
三维空间中的向量 a 与 b：b 绕竖轴转动，点积随之变化；再从 a 的端点垂直落到 b 上，得到投影。
:::

坐标网格上画出两个向量 a 和 b。

b 绕竖轴转动，左上角的点积 a·b 跟着变。

从 a 的端点作虚线垂直落到 b 所在的直线上，红色箭头就是 a 在 b 上的投影。

(matrix)=
## 矩阵变换平面：正交相机与逐帧改写的网格

(matrix-scene)=
:::{scene} matrix
:durations: 0.8, 1.6, 1.6, 1.6
一个二阶矩阵作用在平面上：网格、基向量与单位正方形跟着矩阵变形，行列式标在正方形中间。
:::

单位矩阵下，网格就是原来的方格，单位正方形的面积是 1。

切变把 î 留在原地，ĵ 向右倾斜，面积不变，行列式仍是 1。

换一个一般的矩阵，方格变成平行四边形，面积放大到 1.75 倍。

两列成比例时，整个平面被压到一条直线上，行列式变为 0。

(lorenz)=
## 坐标轴与轨迹：AxesHelper、刻度标签与逐段画出的曲线

(lorenz-scene)=
:::{scene} lorenz
:durations: 0.8, 4, 2
三维坐标轴上，洛伦兹方程的解从原点附近出发，画出蝴蝶形的吸引子，镜头绕它转半圈。
:::

坐标轴和刻度先出现，三个轴的名字跟着各自的颜色。

洛伦兹方程的轨迹一段一段画出来，在两翼之间来回跳，颜色随时间由青变橙。

镜头绕吸引子转半圈，从侧面看出它是两片近乎平的翅膀。

(surfaces)=
## 曲面之间的变形：ParametricGeometry 与形变目标

(surfaces-scene)=
:::{scene} surfaces
:durations: 1, 1.4, 1.4, 1.2
同一块网格在马鞍面、碗形曲面与猴鞍面之间连续变形，最后叠上网格线。
:::

马鞍面 z = x² − y²：一个方向向上弯，另一个方向向下弯。

同一块网格变成碗形 z = x² + y²，原点成了最低点。

再变成猴鞍面，三个方向向下、三个方向向上。

叠上网格线，看清每个顶点都只是换了高度。

(route)=
## 沿路径运动：曲线、管道与跟拍镜头

(route-scene)=
:::{scene} route
:durations: 1, 1.4, 2.6, 1.2
一次请求的路径：浏览器、网关、服务、缓存与数据库依次出现，管道连起它们，数据包沿管道前进，镜头跟在后面。
:::

请求经过的五个节点依次出现。

一条平滑的管道把它们连起来。

数据包沿管道前进，镜头跟在它后方。

镜头拉回全景，数据包停在数据库。

(galaxy)=
## 着色器里的粒子：Points 与 ShaderMaterial

(galaxy-scene)=
:::{scene} galaxy
:durations: 1.2, 1.6, 2.4, 1.6
六万颗星从中心散开，扭成三条旋臂，内圈转得比外圈快，最后镜头倾斜看到星系的侧面。
:::

六万颗星从中心向外散开，位置全部在着色器里算出。

旋臂出现：越远的星，转过的角度越大。

星系转起来，内圈比外圈转得快，旋臂越缠越紧。

镜头倾斜，看到星系是一个薄薄的盘。

(hanoi)=
## 关键帧数据：AnimationClip 与 AnimationMixer

(hanoi-scene)=
:::{scene} hanoi
:durations: 1, 2.4, 1, 2.4
三个圆盘的汉诺塔：七次移动写成关键帧轨道，正在移动的圆盘变成橙色。
:::

架子转到正面，三个圆盘叠在 A 柱上。

前三步把上面两个圆盘挪到 B 柱，给最大的圆盘让路。

最大的圆盘从 A 移到 C。

最后三步把两个小圆盘从 B 移到 C 上，完成。

(lathe)=
## 旋转体与剖面：LatheGeometry 与裁剪平面

(lathe-scene)=
:::{scene} lathe
:durations: 1, 1.8, 1.4, 1.2
一条轮廓线绕竖轴旋转一周扫出花瓶形的旋转体，再用一个平面把前半部分切掉，露出剖面。
:::

先画出半径随高度变化的轮廓 r(y)。

轮廓绕竖轴转一周，扫出旋转体，体积公式随之出现。

一个平面从前方推进到中间，切掉前半部分。

转动视角，从剖开处看到壁和内部。

(hull)=
## 凸包：ConvexGeometry 与描边

(hull-scene)=
:::{scene} hull
:durations: 1, 1.6, 1.2
一组三维点，凸包的棱一条条画出，再填上半透明的面，位于凸包顶点上的点变成红色。
:::

四十八个点出现在空间里。

凸包的棱一条条画出来。

填上半透明的面，在凸包顶点上的点变红、变大，其余的点都在内部。

(materials)=
## 材质对比：标准、物理、卡通、法线与线框

(materials-scene)=
:::{scene} materials
:durations: 1.2, 1.8, 1.4
同一个环面结用五种材质并排，一盏灯从左向右划过，最后金属材质的粗糙度逐渐增大。
:::

五种材质并排出现：金属、清漆、卡通、法线着色和线框。

一盏点光源从左上方划到右侧，看高光在各种材质上怎样移动。

金属的粗糙度从 0.2 增加到 0.9，倒影从清晰变成模糊。

楼房从地面升起。

太阳从东边升到头顶，影子由长变短。

雾漫上来，远处的楼房渐渐融入背景。
