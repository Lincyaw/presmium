(intro)=
# GSAP：原子动画合集

GSAP 擅长网页元素与 SVG 上由许多小动作排成的讲解：算法的每一步、词元与图的变化、文字出现、描线、变形、沿路径运动。它的时间轴可以精确地跳到任意时刻，每个场景都按步骤的时间播放，前进、后退和导出视频时同一时刻的画面相同。

(stagger-grid)=
## 依次出现：网格上的 stagger

(stagger-grid-scene)=
:::{scene} stagger-grid
:durations: 1.4, 1.6, 1.2
六行十列的方格从中心向外依次出现，一道波从左上角扫过，再逐行缩成圆点。
:::

方格从中心向外依次出现：`stagger` 的 `grid` 与 `from: 'center'` 按到中心的距离排出先后。

一道波从左上角扫向右下角，每格亮一下再暗回去。

从最后一行开始，一行一行地缩成圆点。

:::

标题拆成单个字母，每个字母从自己的遮罩里升起。

第一个词 Attention 变色放大，其余的词变淡。

解释文字按排版后的行拆开，一行一行地滑入。

(morph-svg)=
## 变形：MorphSVG 画出激活函数

(morph-svg-scene)=
:::{scene} morph-svg
:durations: 1.2, 1.2, 1.2, 1.2
一条曲线依次变成阶跃函数、sigmoid、tanh 与 ReLU。
:::

感知机的阶跃函数：小于 0 输出 0，否则输出 1。

同一条曲线变形为平滑的 sigmoid，值在 0 到 1 之间。

再变为 tanh，值在 -1 到 1 之间，以 0 为中心。

最后是 ReLU：负数为 0，正数原样输出。
