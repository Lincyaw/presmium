(intro)=
# Motion：原子动画合集

Motion 适合网页里的图表、列表与 SVG：把一段段动画按时间排进一条序列，弹簧、错开与缓动都是现成的。同一元素的同一属性在一条序列里合成一条轨道，所以拖到任何时刻画面都确定。

(bars)=
## 柱状图换数据：同一属性的多段合成一条轨道

(bars-scene)=
:::{scene} bars
:durations: 1.4, 1.2, 0.8
八个月的销量柱状图：柱子依次长出，换成下一年的数据，最高的一根变成强调色。
:::

柱子从左到右依次长出来，顶上的数字跟着从零数到各自的值。

换成下一年的数据：每根柱子从原来的高度变到新高度，数字也跟着变。

五月最高，它换成强调色，其他柱子淡下去。

(counter)=
## 数字滚动：motion value 与 steps 缓动

(counter-scene)=
:::{scene} counter
:durations: 1.4, 1.8
训练面板上的三个数字：轮数按整数跳，损失下降，准确率上升。
:::

前十轮：轮数一格一格跳，损失很快从 2.31 降到 1.12，准确率升到六成。

再训练四十轮：损失降得越来越慢，最后停在 0.42，准确率 91.3%。

(reorder)=
## 列表重排：冒泡排序的每一趟

(reorder-scene)=
:::{scene} reorder
:durations: 1.5, 1.1, 1.1, 1.0
六个数的冒泡排序，每一步是一趟，较大的数从上方越过较小的数。
:::

第一趟：相邻两个比较，前面大就交换，9 被一路换到最右边。

第二趟：8 归位到倒数第二格。

第三趟：2 和 1、5 和 3 交换后，整列有序。

排好了：从左到右依次亮起。

(packet)=
## 关键帧与 times：一次往返与三次握手

(packet-scene)=
:::{scene} packet
:durations: 2.2, 1.8

(canvas)=
