# 界面设计参考（N-10，WP-95a）

用户在 2026-10-17 选定：**工作台的布局与编辑方式，书卷的样式**。三个候选方向与选定的组合都在设计画布上：https://claude.ai/artifact/SRU7x8aHG8qsUitZcC8m2W（私有，只有用户能打开）。本目录保存选定的参考稿。参考稿是带内联样式的静态 HTML，`{{c.xxx}}` 是下面令牌表中的颜色；每个文件末尾的脚本列出明暗两套取值。

| 文件 | 画面 |
|---|---|
| `home.dc.html` | 工作区首页（启动台） |
| `edit.dc.html` | 文档的编辑模式 |
| `slide.dc.html` | 幻灯片（书卷样式） |

## 布局（取自“工作台”）

- **活动栏**：最左一列，从上到下依次是 Presmium 标志、文档、搜索、修改历史、课堂；使用说明与模型设置在底部。
- **工作区侧栏**：文件树，即文档目录与 `presmium.workspace.yaml`。
- **首页是启动台**：
  - 顶部有搜索（`Ctrl K`）与“新建文档”；
  - 文档以卡片列出：衬线标题、一句说明、页数、语言与检查状态；
  - 一张虚线卡片“由 AI 起草一份文档”；
  - 两个小卡片：“最近修改”（来源标签 AI、编辑、文档）与“连接外部 agent（MCP）”（地址与复制按钮）。
- **状态栏**：底部一行，等宽字体。显示 git 分支与未提交数、模型状态、课堂状态、当前文件的语言与行号。
- **编辑模式**：
  - 顶栏：路径、打开的文件标签（未保存的有圆点）、预览视图切换（文档、放映、幻灯片）、“提交 N 处修改”、AI 开关；
  - 中间左右分栏：左边是源码编辑器，右边是实时预览；在预览中点选的块在源码中高亮，反之亦然；
  - 源码下方是问题面板，列出编译诊断，带快速修复；
  - 右侧停靠 AI 修改：对话、差异、接受与拒绝，输入框带上选中的行。

## 样式（取自“书卷”）

| 令牌 | 亮 | 暗 | 用途 |
|---|---|---|---|
| `bg` | `#F7F5F0` | `#161614` | 页面底色（纸色） |
| `surface` | `#FFFFFF` | `#1F1E1B` | 卡片、面板、预览 |
| `sunk` | `#EFEBE3` | `#2A2925` | 活动栏、状态栏、分段控件底色、代码底色 |
| `code` | `#FBFAF7` | `#1A1917` | 源码编辑器底色 |
| `ink` | `#1C1B19` | `#EDEAE3` | 正文；主按钮底色（主按钮为墨色底、纸色字） |
| `muted` | `#5C584F` | `#A9A498` | 次要文字（对 `bg` 满足 AA） |
| `line` | `#E3DED3` | `#33312C` | 分隔线、边框 |
| `line2` | `#A39C8E` | `#6F6A60` | 虚线框、行号 |
| `accent` | `#0F5F5C` | `#6FC1B9` | 强调（深青），选中、链接、当前项 |
| `accentSoft` | `#E2EEEC` | `#1D3330` | 强调的浅底 |
| `selected` | `#EAF3F1` | `#1B2B29` | 选中的块或行 |
| `ok` / `okSoft` | `#2F7D4F` / `#E3F0E6` | `#5CC08A` / `#1B2E22` | 成功 |
| `warn` / `warnSoft` | `#9A5B13` / `#F7EBDA` | `#E3A659` / `#3A2C19` | 警告、未保存 |
| `add` / `del` | `#2F6B3A` / `#A3321C` | `#8FD3A0` / `#EE9A86` | 差异 |

- 字体：
  - 界面用 IBM Plex Sans；
  - 标题与阅读正文用 Source Serif 4；
  - 代码与元信息用 IBM Plex Mono。
  - 这三种西文字体随包发布（Fontsource 的包，OFL），不从网络加载（N-03 离线）。
  - 中文先用系统字体：黑体用 PingFang SC、Microsoft YaHei、Noto Sans CJK SC；宋体用 Songti SC、Noto Serif CJK SC、Source Han Serif SC。设计稿中的 Noto Sans SC、Noto Serif SC 只是示意，不随包发布（体积大）。
- 圆角：控件 8 px，卡片 12 px，幻灯片中的面板 14 px，标签 999 px。
- 阴影：只用于分段控件的选中项与浮层（`0 1px 2px rgba(0,0,0,.08)`）。不用渐变。
- 图标：1.7–2 px 描边的线性图标，不用 emoji。
- 幻灯片：纸色底，衬线大标题，章节名用强调色的小号字，底部是步骤条与页码，代码不小于 18 px（R-27）。

## 实现（WP-95b 至 WP-95e）

- 令牌、字体与通用组件在 `@presmium/host`（`packages/host/src/design/`），工作台、阅读页与编辑模式的外壳在 `@presmium/web` 的主题，工作区的项（文件树、源码编辑器、修改历史等）在 `@presmium/workspace` 的浏览器插件；说明见 `architecture.md` 5.10 与 5.11 节，验收用例是 `e2e/design.spec.ts` 与 `e2e/editing.spec.ts`。
- 与参考稿不同之处：
  - 亮色的 `ok` 加深为 `#2B7449`：参考稿的 `#2F7D4F` 在 `okSoft` 上只有 4.3:1，“检查通过”这样的徽标达不到 AA。
  - `line2`（实现中的 `line-strong`）加深为亮 `#8C8577`、暗 `#78736A`，用作输入框、搜索框与分段控件选中项的边框：参考稿的输入框用 `line` 作边框（亮色 1.34:1），选中项只靠底色区分（1.19:1），都达不到 WCAG 1.4.11 要求的 3:1。
  - 源码编辑器的行号用 `muted`：参考稿的 `gutter`（`line2`）在 `code` 上只有 2.6:1，行号是文字，达不到 AA。令牌 `gutter` 保留。
  - 新增 `danger`、`danger-soft`，用于删除与失败的提示。
  - 启动台顶栏在“新建文档”之前还有“管理文档”，打开重命名、复制、删除的对话框；侧栏标题旁不放“新建文档”。
  - 首页侧栏的工作区名是页面的 `h1`；侧栏隐藏时（宽度小于 1024 px）它在启动台的顶栏，代替“启动台”。活动栏之前有“跳到内容”的链接，键盘到达时才显示。
  - 启动台的搜索在框下列出找到的文档、章节与命令，分组显示；参考稿只有提示文字。文档卡片不随搜索筛选，搜索一个章节时卡片照旧。
  - 宽度小于 1024 px 时侧栏收起，文件树在活动栏的“工作区文件”打开的抽屉中；参考稿的 390 宽画面把侧栏排在启动台之上。
  - 状态栏右端是明暗切换，不显示版本号；git 一项显示分支与未提交的文件数（不是 git 仓库时说明）。
  - 文档卡片的说明、页数与检查结果在站点的文档列表带有它们时才显示（文档编译过之后；搜索框第一次聚焦时其余文档在后台编译）。
  - 编辑模式：
    - 顶栏中，文件标签之后有“打开文件”的菜单（列出文档的文件，末项关闭当前文件）；参考稿只画了两个标签。顶栏末端除“提交 N 处修改”与 AI 开关外还有工具栏的其他项（修改历史、退出编辑等）。
    - 预览视图是“文档”“放映”两段；“幻灯片”在文稿有幻灯片形态时是一个链接（打开幻灯片形态的当前页），不是第三段。
    - 问题面板只有“问题”一个标签（参考稿另有“运行输出”）；诊断没有结构化的修改建议，所以没有“快速修复”的按钮，诊断的 `hint` 写在说明之后。
    - 预览没有“实时预览 · 0.3 秒前更新”的提示行：保存之后页面直接更新。
    - 宽度小于 960 px 时与参考稿换行一样上下排列：顶栏换行（位置、文件标签、视图与工具栏），然后是源码、预览、停靠栏。
  - 幻灯片的运行面板（`slide.dc.html`）：
    - 顶栏在语言与运行位置之后还有参数的输入框（参考稿的例子没有参数）；顶栏放不下时参数与运行按钮一起换到第二行。
    - 运行之前没有输出面板，代码占满宽度；运行后输出在代码旁边（宽度够时），窄处（网页的正文栏、手机）在代码之下。输出之下另有运行的历史与两次运行的对比（P-20）。
    - 录制的输出（运行没能进行时）标题只写“输出”，不写耗时，下面的徽标写明原因。
  - Mermaid 的图在网页与放映视图中用令牌的颜色；幻灯片中只有连线标签取令牌，其余仍是 Mermaid 的 `default`、`dark` 主题。
