# RFC：内容、编排与放映工作台

状态：交互决策已确定，待分期实现。更新日期：2026-10-25。

本文确定 Presmium 作者工作台的 UI/UX，供产品、设计、开发与验收使用。工作台以一份文稿为中心，提供“内容”“编排”两个创作工作区，以及“放映”“导出”操作；常用工具以图标呈现。

本文覆盖 `design-dsh.md` 第 7 节中的旧界面方案，是工作台 UI/UX 的唯一决策源。dsh 接入、工作区服务与预览协议仍由 [工作台设计](design-dsh.md) 定义；源码语义由 [IR 规范](ir.md) 定义。本 RFC 描述目标行为，不表示当前服务已经完成迁移。交互草图用于演示流程，冲突时以本文的状态规则和验收标准为准。

## 1. 决策与边界

作者先编辑页面和内容块，再按步骤编排讲稿、配音与字幕，最后放映或导出。三个阶段共用文稿、位置和编译结果。正文不会因为进入放映而变成字幕，讲稿也不会作为第二份正文出现在内容画布中。

| 参考形态 | 采用的交互 | 在 Presmium 中的边界 |
|---|---|---|
| [飞书文档](https://docs.feishu.cn/docs) | 块编辑、就地修改、批注 | 处理正文与内容块 |
| [Overleaf](https://docs.overleaf.com/navigating-in-the-editor/working-with-the-pdf-viewer/pdf-viewer-options-and-navigation) | 源码与结果分区、双向定位 | 处理当前块的源码、编译状态和预览 |
| [剪映／CapCut](https://www.capcut.com/resource/how-to-use-capcut) | 预览、时间线、所选片段属性 | 处理步骤、配音与字幕的时序 |

保留 React、BlockNote、CodeMirror、现有编译器和 IR。通用控件经公开接口复用 Radix Primitives、react-resizable-panels 与现有设计组件；图标统一经 `@lincyaw/design` 使用 Lucide。此次设计不引入第二套文稿格式、项目级 IDE、通用视频剪辑工程或 Vue 运行时。

正文编辑、步骤编排和画面预览不依赖模型。配音只在作者配置了对应语音服务并主动生成时使用该服务；AI 助手始终是可选工具。

“内容”“编排”是创作工作区；“放映”是播放状态；“导出”是任务。渲染端 ID、录制轨和输出格式不作为工作区标签。日常操作栏不再排列“文档／放映”“编辑／查看”“幻灯片／视频”等多组并列切换。

## 2. 用户对象与统一术语

| 名称 | 含义与数据来源 | 界面约束 |
|---|---|---|
| 文稿 | 一份 MyST 文稿、引用代码与资源 | 顶部显示文稿标题 |
| 页面 | 一个 `IRSection`，放映时对应一张幻灯片 | 页面标题、编号和缩略图用于导航 |
| 内容块 | 页内的正文、代码、动画或插件内容，对应 `IRBlock` | 正文直接编辑；生成内容编辑其源码 |
| 步骤 | 页面内的一个可定位视觉状态 | 显示序号，绑定讲稿与播放位置 |
| 讲稿 | 作者为某页某步骤编写的讲解，对应 `{narration}` 或独立讲稿源文件 | 在步骤属性中编辑，字段统一叫“讲稿” |
| 配音 | 由讲稿生成或由作者录制的音频 | 显示来源、可用状态和实际时长 |
| 字幕 | 播放时显示的文字，由讲稿或录音对应文本生成 | 默认跟随文本来源，不重复维护一份可编辑正文 |
| 转写文本 | 识别录音得到的文本，属于录制轨 | 明确标识录音来源，与讲稿保存目标分开 |
| 编排 | 步骤、画面、配音和字幕在同一时间轴上的安排 | 由既有讲授计划和 `LectureTrack` 派生 |

“逐字稿”“这一刻要讲什么”“我来试试”“回到讲授”退出工作台的常规文案。“讲授轨”等内部领域名保留在技术文档与协议中，作者界面按用途使用“配音”“录音”“字幕”。录音识别文本不能只改名为讲稿后直接写入 MyST。

新文稿使用 `contentModel: blocks`。正文来自 `role: visual`，字幕与配音的文本来自显式讲稿；旧文稿继续兼容隐式讲解，进入工作台时标识其来源。迁移必须保留原文和步骤绑定，不允许通过重命名或重新排序静默转换语义。

IR 步号从 0 开始，界面从 1 开始；`IRSection.steps` 是最后一个步号，因此页面有 `steps + 1` 个状态。只有初始状态的纯文字页面也可编写讲稿，其单一步骤控件默认收起。完整文稿与特定媒介的步号通过 `trail`、`stepMap` 换算，不直接复用过滤后的序号。

## 3. 外壳与信息层级

### 3.1 固定区域

| 区域 | 内容工作区 | 编排工作区 |
|---|---|---|
| 应用栏 | 文稿路径、标题；助手、更多、设置 | 保持不变 |
| 紧凑工具栏 | 工作区图标、撤消、恢复、保存状态；放映、导出 | 保持不变 |
| 左侧页面栏 | 编号、缩略图、标题、页级更多、新建页面 | 同一列表，保持选中页面 |
| 中间 | 当前页面的 BlockNote 画布 | 当前页面当前步骤的最终画面 |
| 下方 | 不常驻时间线 | 当前页的步骤时间线 |
| 右侧 | 默认收起；按需显示块属性 | 所选步骤的讲稿与配音属性，可收起 |
| 底部状态区 | 保存、编译与诊断入口 | 同一状态来源，加当前播放位置 |

顶部工作区使用两个图标标签，选中态有固定标记和浅色底；切换后始终保留当前页面和步骤。页面目录中的标题是内容标识，不受图标优先规则删减。助手默认收起，打开后不自动移动文稿选择或夺走编辑焦点。

右侧同一时刻只展开一个主要辅助面板：步骤属性、批注、版本历史或 AI 助手。切换面板保留各自草稿。dsh 临时打开的终端、文件或浏览器按需显示，不成为固定的第二套外壳。

### 3.2 图标优先

日常工具栏、工作区切换、块工具、步骤导航与放映控件使用图标按钮。图标决定操作类型，颜色和边框表达状态。禁止用表情符号、临时字符或多套图标库代替统一图标。

| 操作 | 设计系统语义图标 | 可访问名称（zh-CN / en） | 常驻文字 |
|---|---|---|---|
| 内容工作区 | `document` | 内容 / Content | 无 |
| 编排工作区 | `arrange`，新增 Lucide `Clapperboard` 映射 | 编排 / Sequence | 无 |
| 页面栏 | `navigation` | 页面 / Pages | 页面标题和编号 |
| 新建页面／插入块 | `plus`，由所在区域区分 | 新建页面 / New page；插入块 / Insert block | 无 |
| 撤消／恢复 | `undo` / `redo` | 撤消 / Undo；恢复 / Redo | 无 |
| 源码／预览／分屏 | `code` / `eye` / `split` | 源码 / Source；预览 / Preview；分屏 / Split | 无 |
| 步骤 | `steps`，配合数字 | 步骤 N / Step N | 数字与范围 |
| 讲稿 | `edit-text` | 讲稿 / Script | 编辑器字段名保留 |
| 配音／字幕 | `audio`，新增 Lucide `AudioLines` 映射；`captions` | 配音 / Voiceover；字幕 / Captions | 参数和状态保留 |
| 同步／动画结束后播放 | `timing-during` / `timing-after`，新增 Lucide `AlignStartVertical` / `ArrowRightToLine` 映射 | 同步播放 / With animation；动画结束后播放 / After animation | 属性选项保留简短名称 |
| 放映／播放／暂停 | `slides` / `play` / `pause` | 放映 / Present；播放 / Play；暂停 / Pause | 无 |
| 上一步／下一步 | `chevron-left` / `chevron-right` | 上一步 / Previous step；下一步 / Next step | 无 |
| 总览／全屏／退出 | `overview` / `fullscreen` / `close` | 总览 / Overview；全屏 / Full screen；退出放映 / Exit presentation | 无 |
| 新建批注／助手 | `comment-add` / `sparkle` | 新建批注 / New comment；AI 助手 / AI assistant | 未处理数量可用角标 |
| 导出／更多 | `export` / `more` | 导出 / Export；更多 / More | 无 |

图标按钮必须有本地化的 `aria-label`，悬停和键盘聚焦显示名称与可用快捷键，触屏有可点击的完整操作菜单。状态控件设置 `aria-selected`、`aria-pressed` 或相应语义；禁用原因可查看。禁止只靠图标颜色、悬停或快捷键暴露功能。

页面标题、字段名、选项含义、时间码、错误及破坏性确认保留文字。菜单和对话框允许图标配合短文字。用户不必通过猜图标来选择配音时机、确认删除或理解编译错误。术语和快捷键在工具提示、菜单及读屏名称中一致。

## 4. 内容工作区

### 4.1 页面管理

页面栏的加号在当前页之后创建独立页面，创建后聚焦新页正文。页级更多提供重命名、复制、删除和移动；拖动页面只改变页面顺序。块的插入加号在当前页插入内容块，不创建页面。斜杠菜单中的“新建页面”必须带页面图标，并明确创建页级对象。

新建页面前完成待写回正文；以当前 IR 边界、稳定章节标签和源版本插入页面。创建、复制、删除和移动分别成为可撤消的文稿修改。删除含讲稿的页面时说明关联内容；失败或来源边界不明确时保留原文和草稿。编译确认新页存在后才移动选择，不能先显示一个尚未保存的假页面。

页面标题直接编辑，普通正文支持 BlockNote 的段落、标题、列表等块转换与排序。不能无损转换的插件块保留类型和源码；转换菜单说明原因，不丢弃不支持的属性。纯文字页面、混合页面和动画页面使用同一套页面管理。

移动页面保留页面和块 ID。移动旧文稿正文块前，将受影响的隐式讲解固定为显式步骤绑定，保持原有讲解位置；不能安全完成时拒绝移动并说明原因。修改动画步骤结构时同步检查已有讲稿和草稿的绑定，不能按新的序号静默接到其他内容。

### 4.2 内容块与源码

生成内容默认显示预览，块头只保留类型图标、源码／预览／分屏图标和更多入口。三个视图对应同一个块。切换不更换动画、不打开场景目录，也不改变块 ID 或步骤绑定。新增动画创建独立定义文件和正文引用，两者以 `source/transaction` 原子保存、共同撤消。

源码从 `ComponentNode.definition` 指向的真实代码读取；没有定义时编辑该块的 MyST 片段。CodeMirror 按需加载。多个块引用同一定义时，以链接图标和数量提示共享关系，应用前可查看受影响块。

源码修改先成为本地草稿，点击应用图标或按 `Mod+Enter` 才保存和更新预览。编译中保持上次成功画面并标识版本；失败时显示块级错误入口，不以空白画面替代上次结果。点击诊断定位到源码，点击预览块定位到对应代码范围。切换视图和预览重载保留草稿、选择与编辑位置。

### 4.3 位置标记与批注

页与步骤标记位于编辑器边缘，使用图标、数字和简短范围，例如“2 · 3”或“2 · 3–6”。正文、动画、仅阅读内容有不同语义图标，工具提示解释含义。标记不进入正文、选择文本、字数、字幕和导出。

普通正文选择和输入不自动展开讲稿属性。点击步骤标记才定位对应步骤；点击讲稿图标进入编排并聚焦当前步骤讲稿。正文画布中不再完整铺开所有讲稿。

选中预览内容时，悬浮入口只保留一个新建批注图标。点击后展开含选中文本的批注表单；`Esc` 先退出表单，再清除选区。BlockNote 自身的文本格式工具仍由编辑器公开接口提供。AI 改写通过当前焦点或批注进入助手，不增加第二排悬浮操作。

## 5. 编排工作区

### 5.1 选择与预览

编排中的画面与放映使用同一查看器、页面比例、主题、字体和步骤计算。下方的页面时间线、步骤选择器与右侧属性都指向同一个当前步骤。点击任一步骤立即定位并显示其画面，无须先播放前序步骤；正序、倒序和随机跳转的同一步骤结果一致。

定位后主动挂载该步骤所需的内容块，不能依赖正文滚动区是否可见。异步动画模块尚未就绪时显示加载状态，失败时提供对应步骤的诊断入口；不能把空白当作步骤已显示。

步骤导航使用数字按钮，空间不足时通过步骤图标展开完整列表。列表显示当前步骤、序号和可用标题，支持键盘选择；全部步骤都可到达。选择页面时恢复该页上次选择的步骤，没有记录时进入初始状态。纯文字页的讲稿入口仍然可用。

选中某步骤后，正文或动画、讲稿、配音状态、字幕和时间线选中片段同时更新。尚无讲稿时显示空输入框，不复制相邻步骤，也不把整页正文当作默认讲稿。

### 5.2 讲稿与配音属性

右侧以“讲稿”为主要编辑字段，下面是配音时机、音色、字幕关系与配音状态。参数有简短字段名，常用操作使用图标。无讲稿、待生成、生成中、可播放、生成失败和内容已更新分别有明确状态。

正文和讲稿默认自动保存；讲稿通过显式 `{narration}` 绑定页内步骤。独立讲稿文件显示来源，沿用其来源写回能力；尚不支持安全写回时只读并给出打开源文件的入口，不转而覆盖 MyST。包含 `{say}`、`{cue}`、停顿或不同媒介范围的内容必须无损保留；简化编辑器无法保留时切换到相应源码编辑入口，不能压平成普通文本。

“生成配音”是显式操作，可选择当前步骤或整份文稿。打开工作区、跳步、打字、编译和进入放映只查询缓存与状态，不隐式调用语音服务。已有的服务提供方说明与外发确认规则继续适用；未配置引擎时就地显示设置入口与具体原因，不影响正文和画面预览。

讲稿修改后字幕立即跟随文本，旧配音标记为需要更新，不冒充新讲稿的音频。当前版本默认使用静音占位和新字幕，不自动播放过期配音；显式查看旧版本时，同时使用该版本的配音与字幕。新生成片段通过版本校验后替换旧片段，失败保留旧片段并标记过期。默认不提供独立的第二份字幕输入框；字幕样式属于显示属性。字幕译文沿用既有翻译能力，其来源关系保持可见。

录音在编排的更多菜单中作为配音来源管理。转写结果在标有录音来源的文本编辑器中修改，仍保存到对应录制轨。要将转写用于讲稿，必须显式选择“采用为讲稿”，显示目标页、步骤与已有讲稿差异，确认后沿用源码版本保存；不自动覆盖作者讲稿。

### 5.3 时间线

底部默认显示当前页的连续时间线，步骤边界可以选择和跳转。画面、配音、字幕使用三条对齐轨道，轨道头以图标表示类型；配音使用波形，字幕使用文本片段，画面按步骤分段。颜色区分轨道，选中态另有轮廓与位置标记，不能仅靠颜色识别。

时间线支持选择片段、点击时间尺定位、拖动播放头、播放／暂停、缩放和适配当前页。步骤列表提供不依赖拖动的跳转。播放头所属步骤是画面与属性的唯一选择；播放跨步骤时，两者一起跟随。点击片段或步骤先暂停并定位到对应步骤起点，点击时间尺则暂停并定位到所选时间。聚焦讲稿或开始修改属性前先暂停、固定编辑目标，禁止自动播放在输入过程中切换目标。

首期不支持自由拖动讲稿到任意页面、把音频跨步骤拆散或任意剪断生成动画。配音起点由时机选项确定，字幕跟随文本和配音。时间线是既有讲授计划的编辑视图，不新增独立时间线文件。

| 配音时机 | 画面与配音关系 | 步骤时长 |
|---|---|---|
| 同步播放，`during` | 动画与配音同时开始 | 同时满足动画结束和讲稿播放结束条件，停顿沿用既有计划 |
| 动画结束后播放，`after` | 最长动画完成后开始配音 | 动画完成后追加讲稿播放，停顿沿用既有计划 |

多个动画使用该步骤声明时长的最大值；纯文字页面的动画时长为 0。配音时长来自实际片段，无片段时以明显不同的占位样式显示估算时长。上述关系用于说明时机，最终起止时刻始终由既有讲授计划的事件序列派生，包括 `{cue}`、段落间隔和显式停顿。不能另算一条互相冲突的时间轴。例如没有额外停顿时，动画 3 秒、配音 5 秒的两种模式分别占用 5 秒和 8 秒。

不能确定动画时长时标为未知，不把估算展示为精确结果；依赖结束时间的 `after` 配音和导出要求先提供有效时长。切换配音时机后，轨道起点、总时长、预览和导出计划同时更新。

## 6. 统一位置、草稿与编译状态

### 6.1 位置规则

工作台保存文稿、章节 ID、可选块 ID、完整文稿步号、`trail`、步内播放位置，以及当前工作区。现有契约没有独立稳定 Step ID；不能把界面序号或数组下标当作跨版本身份。讲稿草稿还绑定实际源文件、源范围与读到的版本。

| 动作 | 位置和播放行为 | 草稿行为 |
|---|---|---|
| 内容与编排互切 | 保留页、块、步骤和步内位置，停止音频 | 保留所有草稿，不改变保存目标 |
| 选择另一页或步骤 | 暂停；定位目标页、步骤和起点 | 旧草稿按原锚点保留，属性立即显示新目标 |
| 源码／预览／分屏互切 | 保留同一块和步骤 | 源码草稿继续保留 |
| 进入／退出放映 | 保留当前页、步骤、工作区返回点；进入时不自动出声 | 不隐式应用源码草稿 |
| 与当前步骤无关的编译更新 | 保留仍有效的位置 | 不覆盖草稿；采用对应修订的结果 |
| 当前步骤的画面或讲稿发生修改 | 暂停并保留页、步骤；该步骤的播放位置归零，等待显式继续 | 保存后更新相应来源和配音状态 |
| 页面或步骤被删除、重排后无法确认对应关系 | 暂停，报告原位置失效，由作者重新定位 | 保留原草稿，不按新数组下标自动重绑 |

切换选择后不允许出现“画面在新步骤、右侧仍编辑旧步骤”的状态。旧草稿通过未保存标记和草稿入口恢复。保存回调必须携带发起时的目标、源版本和草稿修订，不能取响应到达时的当前选择。回调只确认发出的文本快照；保存期间在同一目标继续输入形成的新草稿不得被旧回调清除，而应继续排队保存。

进入放映前顺序完成待保存的正文与讲稿，并等待对应修订的编译结果；准备过程可取消，画布保持可见。保存或编译失败时保留工作区与草稿，可以从状态菜单显式选择上次成功版本放映。源码草稿不自动应用；存在源码草稿时，入口以非模态提示说明将使用已编译版本，不能把草稿显示为已包含在放映画面中。

### 6.2 保存与版本

正文和讲稿在输入停顿或失焦后按目标合并保存，中文输入法组词期间不提交。源码显式应用。切页、新建页面或应用同文件源码前，顺序完成该源文件所有待写回的正文与讲稿；同源写入串行校验版本和范围，不能让自己的两种编辑互相覆盖。冲突时保留草稿并停止依赖该保存的操作。网络断开或 AI 持有编辑锁时说明状态，不能显示为已保存。

草稿按工作区、文稿、来源和锚点隔离，可本地恢复，但只作为未提交编辑状态。MyST、定义代码和既有录制文件仍是事实来源。BlockNote JSON、时间线布局和字幕面板都不成为第二份文稿。

自动保存、源码应用、页面操作和 AI 修改沿用既有版本、冲突、审阅、撤消与恢复流程。输入框内撤消由编辑器处理；焦点离开输入框后，工具栏撤消作用于文稿版本。保存失败和外部变更不丢草稿，不自动覆盖新源文件。

### 6.3 状态与诊断

| 状态 | 表达与恢复 |
|---|---|
| 保存 | 已保存、保存中、本地草稿、冲突或失败；按受影响目标显示 |
| 编译 | 待更新、编译中、预览就绪或失败；标识正在显示的源修订 |
| 配音 | 待生成、生成中、可播放、过期或失败；显示实际或估算时长 |
| 导出 | 排队、运行、完成、失败或取消；标识产物所用修订 |

常态用紧凑状态图标，异常显示简短原因并可展开详情。“已保存”仅说明源码落盘，不代表编译、配音和导出已完成。后台旧任务的结果不能覆盖更新后的预览或配音状态。

编译失败保留上次成功预览，清楚标识其版本；尚无成功预览时显示可恢复的空状态。语音引擎缺失等可预期失败不能使整个画布空白。预览中的静音占位明确提示，不伪装成正常音频。

诊断按块、步骤和任务定位。详情可复制错误、来源、修订、任务 ID 与相关日志；运行时错误、资源加载失败和语音失败均进入既有诊断快照，前端与 agent 可读到同一问题。日志不展示凭据。原始堆栈不常驻正文画布。

### 6.4 批注、助手与历史

批注保留选中文本、位置、内容、时间和处理状态，按工作区和文稿在本地保存。批注可逐条或批量发送给 AI，发送入口使用助手图标和未发送数量角标，完整动作在工具提示和菜单中说明；也可解决、重新打开或删除。未发送批注的编号和选区标记不进入产物。

助手请求先绑定当前文稿与焦点，再交给既有会话。打开助手、切换会话或点击源码链接不改变未提交草稿。AI 修改沿用审阅流程，接受或拒绝时保持作者位置；编译显示对应版本后，仅短暂标记受影响内容块。历史面板保留每次修改的来源、时间、撤消和恢复状态，查看旧版本不静默覆盖当前文稿。

## 7. 放映与演讲者视图

### 7.1 观众画面

点击放映进入最终页面画面，隐藏页面栏、BlockNote、源码、时间线、属性和 AI 面板。底部使用小图标提供播放／暂停、上一步、下一步、步骤总览、字幕、演讲者视图、全屏和退出；次要设置收进更多菜单。页码、步号和时间码保留紧凑数字，不显示整排文字按钮。

控件和字幕有明确布局空间，不能遮住正文。按文稿比例将整张页面缩放到剩余画布，长正文与列表参与完整排版；无法在允许字号内容纳时给出溢出诊断与拆页入口，禁止只保留最后一行或让顶部越过边界。观众端不加载块编辑器和作者属性。

进入放映只准备现有播放数据，不自动播放、不自动合成。手动推进与自动播放共享当前位置。播放过程中手动跳步或操作互动内容时先暂停；继续播放从当前明确的位置开始。无需“我来试试／回到讲授”第二套模式。只有阅读场景需要完整文字时，提供只读字幕列表，列表不挂载编辑、转写或合成工具。

### 7.2 作者演练

从工作台放映时，讲稿图标可以暂停播放并展开当前步骤属性。该面板只显示在作者所在工作台，不进入观众窗口、静态产物或导出视频。修改后留在同一页和步骤，按第 6 节处理播放位置和配音过期状态；收起面板后由作者点击继续。

演讲者视图提供当前页、下一页、当前步骤讲稿、计时和播放控制。观众窗口仅同步画面、步骤、字幕与播放状态，不接收草稿、AI 对话或编辑控件。退出放映恢复原工作区、面板开合和有效位置，音频和订阅按需暂停或释放，不能叠加第二个播放器。

### 7.3 快捷键

| 范围 | 快捷键 | 操作 |
|---|---|---|
| 源码编辑器 | `Mod+Enter` | 应用当前块源码 |
| 编辑器外 | `Mod+Z` / `Mod+Shift+Z`，Windows 兼容 `Ctrl+Y` | 文稿撤消／恢复 |
| 放映，输入框外 | `←` / `→` | 上一步／下一步 |
| 放映，输入框外 | `Space` | 播放／暂停 |
| 放映，输入框外 | `O` | 总览 |
| 放映，输入框外 | `Shift+F` | 全屏；`f` 继续保留给讲台冻结画面 |
| 浮层或放映 | `Esc` | 先关闭最上层表单或面板，再退出放映 |

快捷键不抢占文本输入、输入法、编辑器和交互组件已有按键。触屏用户通过图标、菜单和步骤列表可完成同样操作。

## 8. 导出与输出一致性

导出图标打开格式面板。常用格式以图标、格式名和简短用途显示，例如视频、PDF、PowerPoint、网页；实际可用项来自渲染端和插件，不硬编码当前文稿不支持的输出。高级格式放在展开区域，不能把导出器列表铺成常驻工具栏。

放映和视频消费同一讲授计划、步骤映射、字幕与动画时长。点击导出前，明确使用的已保存修订；有待应用源码或失败编译时说明尚未包含的修改。请求经既有 jobs 流程执行，复用同修订任务，展示进度、取消、失败原因和日志；完成后可以预览、打开或下载。

配置了配音的视频导出要求对应语音片段齐全且有效。缺失或过期时定位到受影响步骤并提供生成入口，不输出看似成功但缺音频的视频。作者可显式选择无配音输出，此时说明字幕和时间的处理方式。对外发布与学生版本继续沿用受众筛选，作者讲稿和工具不得因面板隐藏而误入产物。

## 9. 视觉、窄屏与可访问性

界面使用平整的工作区、细分隔线和受控的主色选中态。文档纸面、最终画面和输入区域是主要表面，避免每行、每组工具都套卡片。内容排版与工具排版分开：正文沿用文稿字体，界面使用设计系统无衬线字体，源码使用等宽字体。

尺寸、颜色、间距、圆角、阴影和动效只来自 `packages/design/src/tokens.css`。常规与紧凑图标使用已有 `--pm-size-icon`、`--pm-size-icon-sm`；缺少触摸热区、时间线或面板令牌时先扩展设计系统，再供组件使用。新增语义图标统一登记到 `icons.ts`，不在业务组件内写 SVG 路径或图标尺寸数字。

桌面允许拖动分栏。宽度不足时先收起助手和次要面板，再将步骤属性改为抽屉；小于 768 px 时单主区域显示，页面目录与属性按需展开，编排画面与时间线纵向排列。切换不丢草稿；不为了保留三栏而把画面缩成无法阅读的缩略图。时间线可滚动查看时间范围，步骤列表始终提供完整跳转。

图标在桌面也优先使用，不能等到窄屏才去掉文字。触屏有效点击区域至少 44 CSS px，图形本身保持紧凑；用令牌实现，不靠放大所有图标。正文对比度达到 WCAG AA，必要控件边界达到 3:1；轨道、错误和选中态同时有形状或文字语义。所有功能可用键盘访问，浮层有正确焦点归还，减少动态效果时仍能判断步骤和状态。

界面文案按包维护 zh-CN 与 en，工具提示和读屏名称也须完整。工作台语言跟随 dsh，产物语言跟随文稿 `lang`，不改变原有规则。

## 10. 实现边界与取舍

| 边界 | 复用内容 | 本轮要求 |
|---|---|---|
| design / 通用组件 | `PmIconButton`、Radix、令牌、Lucide 语义图标 | 完善提示、选中态、热区和图标覆盖 |
| workbench | `DocumentEditor`、`NarrationPanel`、版本和诊断状态 | 统一工作区、位置、按目标草稿和步骤属性 |
| viewer / 预览协议 | BlockNote、CodeMirror、`go`、`position`、`trail`、块锚点 | 保持同一查看器实例，步骤与源码／预览双向定位 |
| workspace | `source`、`source/transaction`、`ir/events`、history、review、jobs | 保存顺序、冲突、最新修订与编译任务反馈 |
| addon-lecture / speech | 讲授计划、`LectureTrack`、`MediaClock`、合成缓存 | 编排和放映消费同一时序，合成由显式操作触发 |
| dsh | 槽位、会话、助手、确认、设置 | 收起式辅助工具，不承担文稿或时间线事实来源 |

现有 `NarrationPanel`、`TranscriptList` 与 `TrackEditor` 分别涉及源码讲稿和录制轨；应复用其服务能力，按来源合并作者入口。观众播放器只保留回放能力。预览协议 v1 不因界面重排自动扩版本；所需新字段必须作为显式契约变更验证，不能把任意文件读写或组件私有状态塞进消息。

| 备选方案 | 取舍 |
|---|---|
| 保持现有布局，仅替换文案和按钮 | 无法解决多套入口、不同文本保存目标和步骤选择脱节，放弃 |
| 同屏常驻文档、源码、时间线、属性和 AI | 窄屏与普通正文编辑空间不足，采用按工作区和选择展开 |
| 以完整视频剪辑工程作为事实来源 | 与 MyST、步骤和讲稿形成重复持久化，保留派生时间线 |
| 改成只编辑源码、整份文稿离线编译 | 失去普通作者的块编辑和逐步骤调试，保留编译式预览与局部编辑 |
| 再换前端框架 | 无法直接修复交互与数据边界，继续 React 体系 |

成本集中在统一选择与草稿、讲授计划可视化、播放位置恢复以及语音任务解耦。若未来需要任意剪辑外部视频、音频跨页自由重排或多个独立时间线版本，再评估独立剪辑模型；若需要跨结构修改长期追踪同一步骤，再扩展稳定步骤身份。当前不预先引入这些模型。

## 11. 实施顺序与验收

| 阶段 | 交付范围 | 结束条件 |
|---|---|---|
| A：入口和图标 | 内容／编排入口、页面栏、紧凑工具栏、术语、放映隔离 | 旧入口移除，所有图标有名称，纯文字页面可编辑与放映 |
| B：位置和草稿 | 统一页／块／步骤、完整步骤跳转、按目标草稿、源码预览 | 任意跳步显示正确，切换与冲突不丢稿、不误写 |
| C：编排和配音 | 页面时间线、步骤属性、显式生成、字幕关联 | 两种配音时机与放映、视频计划一致 |
| D：闭环 | 演练编辑、演讲者视图、导出状态、诊断和窄屏 | 四种显示组合和失败恢复流程通过 |

以下是实施后的验收要求，不是本次文档修改已通过的验证。每个行为安排一到两个真实服务或浏览器场景，以专用小文稿检查。日常不新建测试、不运行测试套件；已有集成测试仅在作者明确要求时定向运行，默认单 worker，不自动扩大范围。验证约定以仓库根目录 `AGENTS.md` 为准。

| 验收场景 | 必须观察到的结果 |
|---|---|
| 页面与块 | 页级加号创建独立页面，块加号仍在本页；纯文字、混合页均可编辑、撤消和放映 |
| 正文和讲稿 | 输入多段正文后全部出现在页面；讲稿只在步骤属性编辑，不自动复制正文 |
| 生成块 | 源码／预览切换保持块身份；新增动画独立定义，共享定义有提示；失败保留草稿和上次画面 |
| 完整步骤 | 首末步骤、后四步、跨页及随机倒序均显示相应画面；完整与过滤媒介步号一致 |
| 时序 | 同步与动画结束后两模式改变实际配音起点；暂停、定位和视频导出使用同一计划 |
| 草稿和更新 | 旧目标保存响应不改写新目标；断网、AI 锁、外部编辑、撤消和编译重载后可恢复正确草稿 |
| 配音来源 | 打开和跳步不触发合成；缺失引擎只影响配音；录音转写不能静默覆盖源码讲稿 |
| 放映 | 没有作者侧栏或大文字工具条，正文无裁切；作者展开讲稿时观众屏不显示编辑器 |
| 返回与播放 | 工作区切换、讲稿更新和退出放映遵循第 6 节，只有一个有效音频时钟和当前位置 |
| 任务和诊断 | 旧修订不覆盖新结果；导出失败可定位，前端错误和后端原因进入同一诊断来源 |
| 图标和语言 | 图标可聚焦并有中英文名称，快捷键不抢输入，触屏无需悬停也可操作 |
| 显示组合 | 浅色／深色 × 桌面／768 px 以下均可操作，至少覆盖 390 px，内容、热区与浮层不裁切 |

实现完成的判断以真实工作台为准。交互草图、DOM 存在、缓存命中或结构检查通过均不能单独替代上述验收。
