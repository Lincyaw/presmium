# Studio 资源标签与问题反馈核对

本次调整来自教师对“预览 / 并排 / 源码”和“文档 / 幻灯片”入口层级的反馈。原界面把文件、布局和产物形态叠成多层选择器；功能测试通过并不能证明操作逻辑连贯。

## 使用规则

- 打开讲义默认激活“文档预览”；文件名、文档预览、幻灯片预览共用中央资源标签栏。
- 打开文件直接编辑，不自动分栏。“打开预览”选择文档或幻灯片，“在侧边打开预览”明确创建右侧预览组。
- 关闭预览保留讲义与源码草稿；合并组回到主组；关闭最后一个源码文件后自动收拢空组。
- 窄屏保留一个“编辑区”入口，文件与预览仍通过资源标签操作。收起聊天后恢复当前资源，桌面分栏缩窄也一样。
- 当前关注内容放在编辑区底部，只在有选区时出现。零问题不显示空问题面板；有问题先显示摘要，再按需展开。
- 嵌入网页不重复提供文档列表和跳转到独立幻灯片资源的链接，课堂工具、放映方式和章节导航继续可用。

单组使用稳定的主标签栏，避免文件与预览互相隐藏整套标签栏时丢失键盘焦点。CodeMirror、各文件的撤销状态和预览池保持挂载。左右箭头在同一组内切换资源；标签获得焦点时 Ctrl/Cmd+S 也能保存。

## 本地代码提示的根因

`addon-code` 曾为每一个没有 Git remote 的代码引用生成 `presmium.code.links` 信息，导致 Python 数据库课程出现三条重复“no remote repository … without a permalink”。本地教学无需永久链接，因此从产生位置移除这条非故障诊断，没有宽泛过滤信息或清空问题列表。

当前 5873 教学体验服务已重启并在浏览器核对，三条信息消失，代码与预览正常。真实执行失败、源文件缺失以及有意义的锚点移动提示仍保留。

## 定向验证

- 新资源标签浏览器用例 2 项：草稿、Undo、左右箭头焦点、标签上的保存、显式分栏、关闭与未保存保护、合并、窄屏及缩窄后的聊天恢复。
- 既有工作台 11 项：快速打开 2、iframe 快捷键 1、Python 编辑/新建/选区上下文 3、预览启动/失败恢复 2、保存同步/诊断点选/阅读与聊天恢复 3。稳定主标签栏后，受影响的 5 项再次通过；预览重载与错误恢复也再次通过。
- 嵌入网页导航与独立网页对照 1 项。
- 本地代码可选永久链接 2 项：无远端时零诊断，同时真实执行失败和源文件缺失仍报告。
- 统一拒绝反斜线路径的工作区服务用例 2 项，保护读取、保存和选区摘录。
- TypeScript、分层、技能与 diff 检查通过。

仅运行相关定向集成验证，未运行全量测试、完整端到端套件或全部课程构建。
