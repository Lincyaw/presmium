每个浏览器实际完成：

1. 打开三页文稿，一个连续原生编辑器，无放映 iframe。
2. 输入正文并等待真实规范 JSON 保存，键盘撤消、重做后分别读回对应正文。
3. 新建第四页，核对页面／块／富文本／步骤身份、4000 ms 停留和 500 ms 停顿，以及原生正文焦点。
4. 在新页输入，使用真实菜单重命名和移动；原内容与身份保持。
5. 刷新后从列表显式重开，保存的正文和四页仍在，没有进入制作或放映。
