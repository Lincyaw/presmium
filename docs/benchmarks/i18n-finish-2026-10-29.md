日期：2026-10-29。分支 `work/i18n-finish-2026-10-29`。依据：[界面术语与文案规范](../glossary.md)、[界面文本审计](i18n-audit-2026-10-29.md) 与三份分片记录（[工作台](i18n-workbench-2026-10-29.md)、[读者与讲者](i18n-reader-2026-10-29.md)、[命令行](i18n-cli-2026-10-29.md)）。没有运行测试套件；验证靠真实运行与 `scripts/check-*.mjs`。

## 1. 规范补缺（`docs/glossary.md`）

按所有者的决定增补：

- 第 1 节：服务商品牌“火山引擎 / Volcengine”；AI 助手的预设名称是产品名 Presmium。
- 第 2 节：命令行的程序名前缀两种语言都用半角冒号加空格（“presmium: …”）。
- 第 3 节：待确认操作的标题是对话框标题，en 用 Title Case。
- 第 4 节：“诊断”一行允许命令行指出日志所在文件时写“日志文件 / log file”；新行“访问令牌 / access token”（工作区服务、MCP、Jupyter 的凭据），“密钥 / API Key”只指模型服务；“图片 / Picture”；“形态”（网站 / Website、幻灯片 / Slides、Notebook、讲授 / Lecture）；“语句 / Sentence”；“授权 / Consent”。
- 第 5 节：滚动叙事 / Scrollytelling、启动报告 / Startup Report、课堂与工具 / Classroom and Tools、笔记 / Notes（与批注区分）、第 N 页 / Page N、当前代码 / Current Code。
- 第 6 节：全屏 / 退出全屏、上一步 / 下一步、重新运行 / Run Again、重新生成配音 / Regenerate Voiceover、复刻音色 / Voice Cloning…（“克隆”仍不用于文稿）、试听 / Play Sample、调整音频片段 / Adjust Audio Clip、时间线片段用“删除 / Delete”、编辑器命令（增加缩进 / 减少缩进、左对齐 / 居中 / 右对齐、删除线、题注、标题行 / 标题列、可折叠列表）；“用 AI 改写”可用；撤消、恢复的快捷键每个平台只写一种（Apple 设备 ⌘Z、⌘⇧Z）。
- 第 7 节：无声播放 / Silent playback、待核对 / Unverified。
- 第 8 节：命令行面向开发者的输出说出 IR 文件时写“运行快照 / runtime snapshot”；标识一行去掉单独的 `token`（移到“访问令牌”一行）。
- 第 9、10 节：记下本次决定；说明严格检查、同一行推荐写法与品牌名的豁免和误报清单。

据此修改的界面文本（两种语言）：Jupyter 的凭据改为“访问令牌 / Access token”；命令行 MCP 一行的中文改为“访问令牌在 … 中”，英文 `watching; IR in …` 改为 `watching; runtime snapshot in …`，帮助中 `print the IR as JSON` 改为 `print the runtime snapshot as JSON`；时间线片段“移除片段 / Remove Clip”“移除音频片段 / Remove Audio Clip”改为“删除”；“试听”的 en 统一为 Play Sample（`Play Standard Sample`、`Stop Sample` 等）；代码来源条 `Current Code`、`Unverified`；编辑器的图片在命令、内容块名与说明中都写 Picture。

## 2. `scripts/check-i18n.mjs` 严格模式

- BlockNote 的文字改为检查工作台合并覆盖后的词典（`blockNoteDictionary()`），不再检查 BlockNote 的原始词典。
- “不用”的词出现在同一行推荐写法之中（“用 AI 改写”中的“AI 改写”、“访问令牌”中的“令牌”、“access token”中的“token”）或品牌名之中（“火山引擎”）时不算。
