# 文档操作的说明精简

删除页面菜单中常驻的复制规则、重命名对话框中的绑定解释，以及导出面板的功能介绍。按钮和字段直接命名操作；真实不可操作原因、删除影响数量、保存失败和草稿恢复反馈保留。文档字幕区仍只开放字幕与配音开始，发音、停留和音频裁切属于视频制作。

页面首尾原先还显示“只能移动相邻的同级页面；封面和章节边界保持原位”。当前 JSON 页面管理按 `sectionOrder` 重排，没有这个旧限制。菜单改为仅显示实际能力返回的原因，首尾方向继续禁用。

Figma 使用既有 Menu 实例 [120:1795](https://www.figma.com/design/CjQ5JFn3PuGXx0NgwYrCR8?node-id=120-1795)，通过公开属性关闭说明，没有新建控件、素材或样式。节点清单同步关闭 `Show description`。

## 实际操作

在独立工作区、动态端口与隔离客户端上启动真实 Studio，通过 Chromium 分别操作浅色／深色的 1440×1000 与 390×844。窄屏上下文启用触屏和粗指针。

`document-quiet-actions.json` 完成 **26/26**：

- 页面菜单只有操作项，首个页面不能上移。
- 重命名自动聚焦标题，原始标题完整；Escape 关闭并将焦点交还原按钮。
- 删除确认仍显示步骤与讲稿数量，取消不修改文稿。
- 字幕侧栏仅有字幕与配音开始，没有发音工具、时长或音频片段。
- 文档导出只显示真实可用目标和生成记录，不再介绍视频与 AI 文件。

三处界面的十二张截图已逐张查看，字段、按钮与菜单均在视口内。前后文稿 SHA-256 一致，文稿写入、语音生成、前端异常和失败 HTTP 均为零。自己的浏览器、服务和临时目录已清理，没有修改公共 4320 服务。

首轮消费者在导出目标的 GET 返回前检查按钮，产生一次失败；记录保存在 `document-quiet-actions-initial-observer.json`。最终操作等待真实 GET 与目标按钮出现，没有为此修改产品行为。
