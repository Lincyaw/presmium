# 放映保存版本确认的真实验证

日期：2026-10-26。使用私有 Studio 17359、真实 JSON 文稿、工作区 API 与浏览器。未修改公共 4320 或用户文稿，未调用模型、配音或其它付费服务。

## 完成行为

正文工具栏的「放映预览」先确认当前保存的文稿能成功编译，再进入放映。准备时使用公共按钮的 loading 状态，正文继续可编辑；新输入、页面变更或切换文稿会取消本次进入。旧响应不能把作者带离新内容。编译错误保留正文与草稿，并通过既有诊断反馈说明问题。

放映工具栏复用公共状态标签与图标按钮，标识「当前保存版本」「正在编译已保存的文稿」「文稿已更新，请重新编译」。刷新图标明确执行「重新编译」。只有确认的文稿指纹与运行修订一致时，画面和步骤控制才作为当前版本显示。正文中的动画卡片复用同一准备边界，缓存只保留最多八个轻量预览引用，不额外保留八份运行 IR 或建立逐块事件流。

## 重开与历史操作边界

重开文稿时，新的 SSE 观察编号不能与旧连接的编号直接比较，否则会把首次通知误判为项目更新。每次成功打开建立新观察基线，并推进本地项目修订以淘汰离开期间的旧预览引用。缓存内容在重新确认期间保持可见和可选择，正文、讲稿与时机入口使用原生只读；确认后恢复编辑。放映编译期间不持有这层重新打开屏障，仍可正常输入并取消旧编译。

新用户示例的真实练习还暴露了复制页经撤消、重做后，目录菜单停留在禁用状态的问题。目录现订阅历史操作的准备与完成状态，历史结束后重新计算页面能力。原操作路径由示例 agent 在独立 Studio 17379 复验，不靠切页刷新掩盖问题。
