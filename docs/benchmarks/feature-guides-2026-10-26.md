## 示例暴露并修复的问题

- 课堂预测的旧相邻块扫描会重组显式内容。现在只校验 canonical 直接子块及目标，不覆盖作者的步骤决定。
- 本地环境与执行面板不能让步骤参数中的旧源码覆盖当前 code child；环境包、显示与执行以同一份代码为准。
- 合法跨行、跨列与列宽组合误拒。校验改为逻辑网格，同时保留重叠、越界和宽度不匹配的拒绝；浏览器核对真实 `rowspan=2`、`colspan=3`、三列 `colgroup`、表头、样式和稳定 ID。
- 表格渲染桥遗漏合并及表头数据；Markmap 注入的默认颜色让暗色标签不清楚。已在公共渲染桥和组件变量中修复。
- 公开阅读页局部动画跳步原先只改时间、不改语义参数，并会发送或跟随整篇导航。现在局部画面使用自己的完整状态，保留原有时钟；Doc 预览与正式放映继续使用共享位置。
- 新作者的命名状态不应依赖迁移专用数字。新导览已移除 22 个 `legacyIndex`，实际 lowering 的运行时章节与移除前完全一致；显式迁移绑定仍保留。
- 网站首页手机菜单原先没有操作。现复用公共 Drawer 与相同导航，实际确认十份文稿地址、关闭、焦点及跳转。
