## 已确认的编辑行为

`doc-authoring-final.json` 完成 17 个动作，记录每一步的入口、模式、当前位置、焦点、保存状态、IR 结构与实际源码：

1. 新建文稿，直接编辑标题。标题中的 `&amp;`、方括号与星号按字面保存，原章节 ID 保留。
2. 新建空白页并直接连打。Enter 后是三个独立 IR 段落；加粗同时具有 IR `strong` 与实际粗体显示。列表具有三项及真实的子项层级。
3. 使用编辑器原生撤消和恢复。初始化不进入撤消栈；正文未确认保存时点击顶栏撤消，文字同时从 DOM、IR 和最终源码消失，原页面 ID 不变。
4. 刷新后从文稿列表重新打开同一文稿，再切换两份文稿。全程保持文档编辑，不打开讲稿、字幕或音色面板，不自动进入放映。
5. 真实中断正文保存请求，保留可见草稿与失败反馈。切换文稿后草稿不串入另一份文稿；回到原文稿恢复草稿，经明确重试后真实写回并清除未保存状态。

已实际打开浅色、深色与 `1440`、`390` 宽度的四张截图检查。正文、粗体和列表可读，根布局、画布与 iframe 没有横向溢出；主题通过设置界面切换，未手改 CSS 类。

`control-final.json` 的最后一轮完成 20 个实际动作，页面异常和 HTTP 失败均为零。撤消后的源码确实删除新增文字，恢复后的源码保留加粗；原页面 ID 与批注标记不受影响。四种组合分别检查了批注标记与字符、格式工具与批注工具的矩形：没有遮挡，八个格式按钮均在视口内。桌面块操作按钮为 `30×30`，触屏为 `44×44` 并纵向排列；窄屏格式工具分为两行。另在 `control-visual-menu.json` 等菜单动画完成后检查四组实际截图，菜单可见且可滚动。

格式工具只开放能写回 Markdown 的能力。实际编辑确认加粗落入源码；下划线、颜色和对齐没有通过当前转换器的持久化检查，因此不作为可保存的格式提供。

`legacy-doc-authoring.json` 完成旧文稿的四项实际浏览器检查：普通旧段换行后两个 IR 块均保留 `narration` 与原步骤；清空、确认保存后再撤消，恢复原 ID 与角色；重新打开仍可编辑；复杂 cue 段落的原生文字修改保留原源码标记和绑定。全程没有页面异常。

`viewer-final-interactions.json` 另确认了精确的单块选区批注、批注时源码字节不变、新段待确认时暂不提供旧锚点、确认后使用真实新 UUID，以及复杂段落的双击文字编辑入口。

`full-document-completeness.json` 最后专门确认了跨章全文。工作台画布使用全部 IR 章节，页面导航只定位，不再沿网站分页卸载其他章节。现代文稿和旧文稿的两个一级标题、两个二级标题与六段正文均完整出现，IR 和 DOM 的章节 ID 顺序相同。往返定位后仍是同一个编辑器节点，原生撤消真实写回；小结输入落到原小结 ID，新建页面后五节仍完整。公开阅读页的负对照继续按章显示且不加载编辑器。最终重新读取源码与 IR，撤消的标记没有反弹，小结的修改仍在。该文稿的浅深色、桌面与窄屏四张截图也已逐张查看，没有横向溢出。

## 版本与能力边界检查

- `doc-source-verification.json`：25 次真实编译，覆盖原生标题、格式标题、BOM/CRLF、Setext、旧段落拆分、cue 保留与拒绝、已发布子段的真实身份、空页清空与恢复、重复标签及空列表占位。字面星号仍按正文保存。
- `body-binding-compile.json`：独立的 9 次真实编译，覆盖旧讲解、受限渲染形态、作者范围和后置时机。错误版本或已清除的绑定在写前拒绝，源码不变。
- `body-bindings-service.json`：真实服务版本与提交链。删除后、同文件另一节保存后再恢复，仍保持原 ID、角色、步骤、形态和作者范围；请求中的错误步号不能改写原绑定。外部改写和文稿作用域清除后拒绝未知绑定。
- `body-ack-scope.json`：真实后端已写入后延迟响应，旧文稿确认不会清除新文稿的输入；隐藏文稿保留新稿而不启动下一次写入，恢复后再保存。新一代连接不重播旧请求回复。
- `body-ack-cancel.json`：真实延迟响应的两种顺序均通过。离开文稿后，排队但尚未写入的请求收到明确延期回复，草稿保留且隐藏时不重试；先返回原文稿并继续输入，再放行旧请求时，新输入仍保留并写回。两种顺序之后的新建页与空块菜单取消均完成真实保存，没有原先的等待超时。未把该结果扩大到未单独验证的所有异步等待位置。
- `context-freshness.json`：完整基本流程的首次记录曾捕获新文稿会话绑定返回 `400`。修复目录缓存失效后，温热目录缓存、界面新建、文件系统新建与恢复当前文稿的真实会话绑定均返回 `200`；未调用模型。

保存确认始终区分源码写入、IR 更新与当前输入版本。删除后的简单块只在当前会话自身已确认的源码版本链中恢复绑定；缓存失效时保留草稿并明确拒绝，不把未知来源默认为普通画面。
