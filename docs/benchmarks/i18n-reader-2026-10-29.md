# 读者与讲者界面文本修正（zh-CN 与 en）

日期：2026-10-29。分支 `work/i18n-reader-2026-10-29`。依据：[界面术语与文案规范](../glossary.md)、[架构 5.7 节](../architecture.md#57-界面语言)、[界面文本审计](i18n-audit-2026-10-29.md) 的第 2 分片。

范围：`packages/host/src/**`、`packages/viewer/src/**`、`packages/web/src/**`、`packages/design/src/**`、`packages/addon-*/src/**`、`packages/addon-*/components/**`。未运行测试套件。

## 改动

- **查看器**：演讲者窗口 → 演示者视图 / Presenter View；退出放映 → 结束放映 / End Show；重新编译 / Recompile → 更新 / Update；讲解 / Narration → 讲稿 / Script；视图菜单的“文档 / Document” → 网页 / Web；“本节”“下一节” → 本页、下一页；“在编辑器中打开源码” → 在编辑器中打开 / Open in Editor；代码块的命令（Run Again、Edit Code、Restore Code、Reset Session、Done Editing、Full Screen、Exit Full Screen、Restart Timer）改为 Title Case；运行失败与缺少组件的提示不再显示执行器 ID 与组件名；代码来源条的“工作区”（与规范中的工作区冲突）→ 当前代码，“待确认” → 待核对，说明补句号。
- **宿主**：启动报告原样显示 `started` 等英文状态，改用目录（`已启动`、`Started`），并显示“正在启动…”“没有注册插件。”；“内核启动中……” → 正在启动…；`Approvals 2` → 待确认 2 / Pending Approvals (2)；对话框关闭按钮的 `'关闭' : 'Close'` 三元式迁入目录；审批失败不再显示 `Error: the server did not take the answer (500)`，改为“无法发送答复。请重试。”。
- **站点外壳**：文档 → 文稿（列表、搜索、空状态）；上一章 / 下一章 → 上一页 / 下一页；en 的命令与区域改为 Title Case（Open in Slides、Skip to Content、On This Page、Page Not Found、Back to Home 等），搜索的直引号改为弯引号；删除未使用、含 agent 与 MCP 的 `mcp` 文本；启动失败时 `#app` 中不再写出原始错误，改为“无法打开此文稿。请重新加载页面。”（原始错误仍在控制台）。
- **插件**：
  - addon-assistant：`chat-client.ts` 在幻灯片中不再读 `<html lang>`，改用 `@lincyaw/host` 的 `currentLocale()`；「」→“”，Cancelled → Canceled，Key → API key，失败写作“无法获得回答：…”。
  - addon-classroom：第 N 节 → 第 N 页；子块 ID → 子内容块；“问题挂在” → 问题将关联到；命令改 Title Case（Open Answering、Save Prediction、New Note、Send to Classroom…）；Oxford comma。
  - addon-exec、exec-local、exec-wasi、exec-webgpu：……→…，运行中 → 正在运行，执行器 ID 不再出现在读者看到的失败中，Cancelled → Canceled，直撇号 → ’。
  - addon-exec-jupyter：令牌 / token → 密钥 / API key；读者文本中不再出现“内核 / kernel”；“构建时” → 导出时；Notebook 中的终端说明从三元式迁入按文稿 `lang` 选择的目录。
  - addon-lecture：讲授轨、录制轨、TTS 音色、合成、旁白、`@lincyaw/addon-speech` 全部按规范改为配音、录音、音色、生成配音；演讲者窗口 → 演示者视图；“工作台未及时确认播放权限” → 无法开始播放。请重试。；静音计划 → 无声播放；译文过期 → 译文需要更新；制作计划 → 编排；手动字幕过期提示、编排中的“第 N 步”、配音试听文字从三元式迁入按文稿 `lang` 选择的目录（试听文字的“旁白声音”→“配音音色”）。
  - addon-motion、publish、session、stage、content：……→…，载入 → 加载，“听众视图” → 观众视图，“撤销” → 撤消，deck → document，Title Case 与弯撇号；addon-speech 的“火山引擎 / Volcengine”两种写法迁入目录对象。

## 规范缺项（交协调者）

- 品牌名单（第 1 节）没有语音服务商“火山引擎 / Volcengine”；脚本把其中的“引擎”当作“不用”的词。
- “代码来源条”中 git 工作副本的叫法：规范的“工作区”指文稿文件夹，本次暂用“当前代码 / Current code”，“待确认”改为“待核对”（规范中“待确认”专指 Pending Approvals）。
- 读者问答的设置项“密钥”：规范为“密钥 / API Key”，字段标签按 sentence case 写作 `API key`；Jupyter 的 token 也按此写作“密钥 / API key”，是否需要单列“访问令牌”请确认。
- 没有“滚动叙事 / Scrollytelling”、“启动报告 / Startup Report”、“课堂与工具 / Classroom and Tools”、“无声播放 / Silent playback”、“重新生成配音 / Regenerate Voiceover”、“语句 / Sentence”（讲授编辑器中的一段配音）、“页面”在课堂位置中的写法（“第 N 页 / Page N”）的条目。
- “Notes / 笔记”（读者笔记）与“备注”“批注”的区分未写入规范。
- “Full Screen / Exit Full Screen”“Previous Step / Next Step”“Run Again”等查看器命令没有条目。
