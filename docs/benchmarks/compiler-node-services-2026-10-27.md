# 无需编译画面的 Node 作者服务

`Compiler.nodeServices({signal?})` 复用编译器原有的文稿校验、插件加载、配置合并和服务注册，返回该次源的 `CanonicalSource`、装配诊断及公开服务查询。它不进入编译队列，不收集组件与执行器，也不运行 IR passes。文稿 JSON 无效仍拒绝，插件加载和配置错误仍保留为真实诊断。

这是音频作者接口使用服务的边界，避免转写能力和任务启动依赖场景编译成功。调用方仍须核对返回来源，实际引擎鉴权与识别能力另行验证；服务装配成功不代表语音请求成功。中途取消在返回前检查，插件 setup 本身没有可中断契约，不能声称其已被强制中断。
