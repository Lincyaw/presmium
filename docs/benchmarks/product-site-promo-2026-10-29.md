## v3 制作与样片复核

v3 的美术与镜头依据在 `examples/presmium-site/promo/art-direction-v3.md`，脚本与分镜在 `promo/storyboard.md`。实际观看 Apple 官方 AirPods Pro 与 iPhone Air 产品影片的构图与镜头，参考帧只保留在临时目录，未进入成片或源码包。放弃过一版串珠造型，最终采用单参数损失形成的白银／石墨薄弧带、紫色轨迹与平面光核。

正式文稿为一个 full 页面、一个场景、九个语义步骤，时长 4／6／6／8／10／6／8／6／6 秒。编译时间线为 60,000 ms，零 narration、`voiceSource: none`，没有旧版口播与烧录字幕。主文案限定为五组；真实公式和一行更新代码短暂作为内容对象出现，17.7 秒前退场。训练与回看复用共享的真实轨迹，画面不会将点吸附到精确最小值。

场景由公开的 GSAP 和 Three.js 适配器组织，采用确定性时间线、摄影棚环境、景深与真实损失曲面。首轮全片样帧发现公式压住主体、训练段长时间重复全景和演示截图顶端残句；修正后重新检查 13／18／30／37／49／51／53 秒。连接段文字移到上方留白并退出；低学习率阶段有跟随推近，回看有同边微距，比较起止恢复完整宽景；光核可追踪。片尾展示两张真实产品截图，第三种视频形态在演示图上叠加播放控件，是图形呈现，不是独立产品截图。

先以原生导出制作独立 10 秒摄影样段：3,792,543 字节，1920×1080、30 fps、300 帧，VP9＋48 kHz 双声道 Opus，容器、视频与音轨均为 10.000 秒；浏览器媒体元素显示 10.020 秒，解码音频约 10.0135 秒，未出现媒体或页面错误。软件 WebGL 下实际导出耗时 133.18 秒。这是摄影样段证据，未将它作为完整影片节奏与声音的验收替代。

全片冻结前的两轮预检覆盖关键结果与切点前后画面。修后预检的 WebGL 和二维文字层均为实际 1280×720 绘图缓冲区，匹配显示尺寸；编译诊断与页面错误为空。曾误用导出专用的单向 `advanceTo` 做 58→30 秒回退，发现该检查不会回折步骤事件，改用正常播放器 seek／全新页面定位核对；没有把这次检查方法错误当作公共播放器缺陷。

音乐来自 `promo/tools/soundtrack.ts` 的确定性原创合成，未使用采样录音或语音合成；WAV 是 48 kHz、双声道 PCM16、60.000 秒。源文件 SHA-256 为 `5e76a54b655b8d4fad4ee283aad6efe5e180b705614a7affc41e358fc19ea753`。九个媒体片段连续引用同一音轨的相邻区间，总计 60 秒。复核者没有可靠地试听 Apple 参考片的完整混音，也没有进行真人冷观众测试。

本轮公共渲染修正：Three.js 绘图缓冲区按实际显示尺度与设备像素比设置，逻辑排版尺寸不变，后处理目标随尺寸通知更新；导出态去掉放映预览留白、阴影与场景圆角。另实际检查了 1280×720 与 320×180 两种场景显示尺寸。

本轮轻量检查：全局类型检查通过 1437 个文件；本例七个 TypeScript 入口的严格类型检查没有本例诊断；令牌检查覆盖 49 份样式，分层检查与 `git diff --check` 通过。首页源码预览实际查看了桌面／390 宽度与亮／暗四种组合，并检查中英文切换焦点、观看按钮启用原生播放器、展开开始命令。成片与最终静态站点的验证另记于下方。

导出前另发现并关闭一处真实几何衔接问题：TubeGeometry 默认按弧长采样，但轨迹 drawRange 按线性 w 比例裁切，回看中段导致轨迹末端与光核约 20 像素分离。两条自定义 Curve 显式统一 `getPointAt`／`getTangentAt` 的参数化后，重看 21／30／37 秒，末端与光核连通；未改变训练计算、材质、镜头或时长。首次完整导出在 180／1800 帧处中止（128.39 秒），没有替换公开成片；最终导出从修后冻结源重新开始。

独立只读代码复审覆盖 Three.js 缓冲区尺寸及调用者、导出态 CSS 作用域、首页路径和控件、双语焦点与减少动态效果支持，没有确认的阻断项、主要问题或细节项；该复审未运行构建、测试或浏览器，不替代上述实画面检查。技能检查与严格 i18n 检查也通过；i18n 命令保留仓库已有允许项与启发式报告。`presmium check promo`、`presmium check learn` 均返回 `no problems`。
