# 页面复制的源事务验证（2026-10-26）

页面更多菜单的“复制页面”将副本放在原页之后。操作读取当前 `TeachingDocument`，经现有 source actor、工作区 HTTP CAS 和领域校验保存；复制与编辑均不等待运行编译。身份、引用和讨论策略见[文稿 IR 契约](../rfc-document-ir.md#五类对象与关联)。

独立 Studio 消费者 `.presmium/ui-evidence/page-copy-consumer.json` 通过 43 项实际检查，浏览器异常、失败 HTTP 与语音生成请求均为零。临时文稿包含嵌套容器、组件子块、列表及引用、合并表格单元格、未知行内与块扩展、图片、代码变体和步骤高亮，两步间继承与共享讲稿、发音、页内外 cue、制作覆盖、真实已有音频文件的媒体片段，以及跨页批注。没有修改 `4320` 工作区。

复制原先会把自身重置时恢复旧选区触发的代次变化当成后来的作者输入，导致已有正文选区时不采用副本焦点。现复用待聚焦契约，明确推迟到源保存确认后采用；真正的后来选择仍优先。修复前的实际输出摘要为 `page-copy-focus-before.json`，修复后的空页聚焦与迟到回执检查在上述 43 项中；摘要没有重建丢失的源文件或截图。

另用实际 Compiler 派生运行 IR，再生成 `lecturePlan`，`page-copy-plan.json` 的 3 项检查通过：副本作为独立页面出现，两步最短停留仍为 `2300 / 1100 ms`，结束停顿为 `210 / 350 ms`，讲稿开始顺序仍为 `after / after / during`。未生成配音或视频，也未声称测量过音频字词对齐。

四组菜单截图为 `page-copy-{light,dark}-{1440,390}.png`。Figma 的[页复制说明示例](https://www.figma.com/design/CjQ5JFn3PuGXx0NgwYrCR8?node-id=120-1795)引用已有 `Presmium/Menu`，公开说明属性与代码相同，没有新增菜单原语或未实现的快捷键；P09 只更新已验证的复制状态，拖动仍标为待实现。

原批注未复制。若跨页线程的原锚点在新副本两侧，原生连续范围仍可能经过副本；线程身份和端点保持原值。验证中点击高亮范围会先选中原线程，退出线程浮层后明确定位正文光标再输入；本次没有改写 BlockNote 的批注交互。窄屏结果来自真实 Chromium 调整视口，不代替系统输入法或触屏设备验证。未新增测试，未运行测试套件；轻量类型、分层、令牌、技能和差异检查通过。
