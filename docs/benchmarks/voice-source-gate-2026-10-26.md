# 配音的保存版本屏障与生成占用

本轮修复了两个服务边界：保存成功但编译未完成时，旧 IR 的报价、试听与生成仍被接受；不同范围同时生成时没有共用的准入限制。所有验证均使用独立临时文稿与真实工作区服务，没有操作公共工作区或调用付费合成。

## 实际验证

脚本位于忽略目录 `.presmium/`，原始记录位于 `.presmium/ui-evidence/`，没有新增测试或运行测试套件。

网络保护拒绝所有外部请求；上述记录的外部请求数均为 0。没有配置可用语音提供方，没有调用付费合成、转写或模型。已有音频来自随文稿保存的精确缓存，未伪造音色或生成结果。

轻量检查通过：类型检查 1129 文件（`/tmp/presmium-voice-source-final-types.log`）、分层检查、技能检查与 `git diff --check`。独立代码审阅补查的最终 await 取消问题已有原始失败与修复记录，最终结论为 APPROVE。

## 契约与边界

`CanonicalSource` 由编译器从实际 canonical 入口生成，包含文稿 ID、保存版本 SHA-256 前 20 位、原始文本 FNV-1a 摘要；BOM 计入摘要。它与运行 revision 分开。报价和任务携带自身来源，确认 POST 回传来源；服务在调度、片段调用与结果采用处重新确认。旧缓存只表示请求文本与音色仍匹配，不能使一个旧任务成为当前任务。

同进程内的生成占用覆盖路由的预检与执行、需要生成的试听和显式 agent 生成工具。它不提供多进程分布式互斥，不宣称对外部提供方的认证、计费幂等或取消退款已经验证。完整 UI、试听播放互斥和实际付费提供方由对应工作区接入另行验收。
