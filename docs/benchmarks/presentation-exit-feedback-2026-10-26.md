# 退出放映后的可见反馈

日期：2026-10-26。用户示例的真实操作记录虽然显示正文恢复、保存和输出成功，四张最终截图仍出现“暂时无法确认放映位置”。`pageerror` 与 HTTP 错误均为零，因此它们不足以证明用户界面没有失败。

## 修复

退出必须先收到子画面的暂停与位置确认。成功后，React 的 `presenting=false` 尚未提交，外部工作台状态可能先切换到正文；若此时清空退出 Promise，视图跟随 effect 会再次发起退出。实现现保留同一次成功退出的 Promise，直到 React 已提交关闭状态才释放。真正失败仍立即释放、显示错误并允许重试，没有吞掉暂停失败或提前销毁画面。
