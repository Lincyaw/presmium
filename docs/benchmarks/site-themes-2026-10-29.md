# 网站主题与独立首页验证

日期：2026-10-29。范围为网页渲染端、建站脚手架、设计令牌与文稿摘要契约。验证使用临时项目和真实 CLI、静态服务、开发服务与浏览器；没有新增测试用例，也没有运行测试套件。

## 实现范围

- `course`、`docs`、`showcase` 三套预置主题与品牌、字体、阅读宽度配置；工作区主题统一、文稿布局独立。
- 独立首页支持 `site.landing.source` 的 JSON 页面、内联页面定义与 `site.landing.template` 的 HTML 入口。教学文稿继续由 `lecture.json` 提供。
- HTML 模板通过 Vite 公开构建 API 打包 CSS、JavaScript、TypeScript 与素材，读取 `presmium-site-data` 中白名单化的文稿集合数据。
- 原有字符串文稿首页与 `site.home` 重定向保留。文稿与译本支持文章、全宽与单页布局。
- 新建网站带独立首页、教学文稿与 GitHub Pages 工作流；本轮没有实际发布到 GitHub。

完整使用方式见[网站主题指南](../site-themes.md)。

## 真实运行

| 场景 | 结果 |
|---|---|
| 三主题、多文稿、`/repo/` 基础路径 | 构建成功；首页、文稿列表、章节直链与导航可用 |
| 教学文稿作为首页，含多个章节与译本 | 根页显示全部章节，独立文稿路径保留 |
| 原文文章／译本单页，以及反向组合 | 分页与外壳一致；跨布局语言切换进入目标语言的有效根页 |
| 实时译本在第二章改为单页 | 只修改译本即收到更新，路由回到语言根页，全部章节显示 |
| 独立 JSON 首页，五类 sections、本地图片与视频字幕 | 构建成功；首页没有教学 IR 地址；视频实际播放，时长 3 秒、宽度 320、`readyState=4`、无媒体错误、1 条字幕轨 |
| 自由 HTML 模板，独立 CSS、TypeScript 和公开文件 | 静态构建及开发预览成功，文稿集合生成可访问链接，CSS 中公开素材带正确基础路径 |
| 没有教学文稿的 HTML 网站 | 构建成功，根页不加载教学文稿运行配置 |
| 含空格的文稿目录与百分号编码链接 | 链接发布为 `/repo/my%20lesson/style.html#publish`，没有把原始 `lecture.json` 放入媒体目录 |
| 无效主题、参数、首页目标、配置冲突和文稿布局 | 构建报告错误；这些结构配置在清空旧输出之前校验 |
| 未编译文稿的首页摘要 | 从已有元数据读取说明文字，无额外编译；已有快照时以快照为准 |

配置式首页已实看亮／暗、桌面／390 CSS px 宽度；新首页没有横向溢出。原三主题的首页或阅读页也按四种组合检查。独立 HTML 示例在浏览器中确认自己的 CSS 和 JavaScript 生效。

可编辑文件和页面素材使用同一来源路径：JSON 素材相对 JSON 文件，内联页面素材相对工作区配置文件。站点绝对导航加上基础路径，文稿文件链接复用既有文稿解析与章节映射，教学源码不能退化为附件发布。

## 图像尺寸修正

预览中的 P 标志最初被放进 Hero 主图。根据作者反馈，将它移至页头，实际显示为 28 × 28 CSS px，移除 Hero 和视频封面中的巨大标志。独立页面主图另增加桌面 24rem、窄屏 13rem 的高度上限并保持完整显示。
