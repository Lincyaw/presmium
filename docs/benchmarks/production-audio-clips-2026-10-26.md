# 本地音频片段：2026-10-26

本轮实现 canonical `production.mediaClips` 的本地音频裁切、音量与静音，复用讲授轨、播放器时钟和 WebM 导出。验证在独立临时工作区与服务运行，未修改公开示例或用户文稿，未停止公共 Studio。未增加测试文件，未运行测试套件、全量示例、付费合成或外部网络请求。

## 可用范围

片段以 canonical `assetId` 引用同文稿非隐藏常规音频文件。Node 通过已有文件描述符边界拒绝符号链接与越界读取，用 Mediabunny 公共 API 确认单音轨、单声道或双声道、实际时长与 MIME，并计算原始字节 SHA-256。每文件至多 16 MiB、10 分钟，每计划至多 32 份音频，按 48 kHz PCM 估算的唯一素材解码总量至多 256 MiB。导出按唯一资源逐一解码，同一素材的多个片段共享只读样本。

`sourceRange` 为毫秒入点、出点；`attachment` 指定稳定 StepID 与步内偏移。片段必须完整处于已确认的步骤时段，不会改变 hold、cue 或跨步。`volume` 为 0..1，`muted` 独立保存，取消静音保留原音量。TTS 与素材并行进入同一 `MediaClock`，字幕仍只来自 canonical Narration。

编译器跟踪引用的实际音频文件，过滤受众时移除被排除步骤的片段及资产投影。计划摘要包含实际素材 SHA、范围、音量与静音；只读资产检查按 AssetID，媒体读取按完整 `ProductionBinding` 与资源白名单。读取与发布前核对文件身份及 SHA，不提供任意路径接口。计划使用的资产元数据与语音缓存条目是两种明确类型，不将导入音频称为已合成语音。

## 边界

本轮没有资产导入表单或二进制事务。调用方须先有 canonical 音频声明与片段；保存确认仅说明文稿合法，实际素材范围、解码能力和步骤容量由制作计划、检查与构建确认。非法物理范围可以保留为作者草稿，但不能取得可预览或可导出的计划。

跨文稿共享、远程音频、视频裁切、录音 VoiceSource 采用仍明确拒绝。复杂 None 文字 cue 没有确认时码的既有门槛保留。未实跑其它编码器、所有音频格式或多声道素材；本轮实际浏览器与导出素材为本地单声道 Opus 和真实现存 TTS 缓存。字幕不会根据独立音频自行生成或改时码；音频变化更新计划身份，不覆盖 canonical Narration。
