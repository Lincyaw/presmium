# 本地音频素材与片段编辑

2026-10-27，在独立随机端口的真实 Studio 中验证音频导入、片段参数、保存与播放。全部文稿是私有副本，使用仓库内的真实 Ogg 音频；没有修改公开 Studio 的文稿，也没有调用语音生成服务。

## 作者操作

视频制作中的“导入音频”只保存素材声明与原始文件。导入后选择该素材，以真实探测时长初始化完整入出点；作者填写入点、出点、步骤内延后、音量或静音，再明确“采用到本步”。已有片段通过“应用”保存，也可恢复完整范围或移除片段。恢复完整只改变草稿，移除保留原始素材。

所有写入仍经现有 Workbench 和文稿 source actor，服务端验证版本、完整计划绑定、真实素材与已确认步骤范围。片段太长时显示字段错误，不改变步骤停留。音量范围为 0–100%，静音不丢音量。滑杆拖动只更新草稿，采用动作提交完整片段一次。

文档编辑页没有增加媒体参数。组件只显示必要标签、时长、操作、未采用状态及真实错误，没有新增常驻机制说明。成功的导入、采用或移除在视频制作中排队准备当前已保存版本；准备过程中收到的新成功意图合并保留，待上一轮结束再处理。自动准备不会开始播放或采用其他草稿。

## 公共组件与设计

先读取正式 P22 页面与 Input、Range、Button，再建立公共 `MediaClipEditor`：Figma 组件集 `168:4683`，检查画板 `168:4684`，Compact／Regular／Touch 各含 Empty、Ready、Invalid、Busy、Unavailable，共 15 个变体。复用现有正式组件实例、令牌与图标，不绘制假波形。

运行实现复用 `PmInput` 的 time／number 宽度、`PmRange`、`PmSelect` 和公共按钮；新增样式属于设计包的公共组件。业务适配器负责目标、真实 inspection、请求和草稿；公共控件不访问 API。登记见 [设计系统](../design-system.md) 与 [Figma registry](../prototypes/workbench/figma-nodes.json)。

## 草稿恢复边界

草稿按客户端、文稿身份和稳定步骤缓存，只保存素材 ID、clip 数值、原始字段文字与版本，不保存 File 或另一份文稿。现有 clip 使用 `clip:${id}` 命名空间，与新片段的 `new` 分开；读缓存条目先检查 own property。

64 是已持久化项的内存淘汰目标，不是未采用草稿总数上限。持久存储只清理空导航记录；含未采用输入的记录不会自动删除。单记录超过 128 KiB 或实际 quota 失败时显示暂存告警，内存保留当前唯一副本；刷新后无法恢复尚未持久化的输入，告警明确要求保留页面。33 个合法条目的写入不会因旧的条目预算提前丢失内存副本。

## 调查中保留的失败

- 首次上传遇到 Dsh 代理缺失路由，真实 404 与源未变记录为 `audio-editor-proxy-missing.json`；代理由桥接提交修复。
- 初版消费者误把刷新后的首页当作仍打开的文稿、一次 multipart 观察器错误，以及一次把滑杆默认字体纳入文本字号检查的错误，均保留原记录。校正消费者，没有为它们修改产品行为。
- ID 冲突前例见 `audio-editor-id-before.json`；快速输入被嵌入预览夺焦点的前例见 `audio-editor-focus-steal-before.json`。后者的根因与独立修复见 [嵌入预览焦点](viewer-embedded-focus-2026-10-27.md)。
- 自动准备首次暴露的 IR 根字段遗漏另见 [运行文稿根属性的实时更新](viewer-root-live-update-2026-10-27.md)。原业务拒绝与后续同 iframe 播放证据分开保存，没有用 HTTP 成功代替业务播放成功。

最终冻结源码的轻量检查为 types 1168、tokens 39、layering、skills 与 diff 检查通过。未验证视频导入、录音、自由剪辑或音频对齐；界面也未提供这些入口。
