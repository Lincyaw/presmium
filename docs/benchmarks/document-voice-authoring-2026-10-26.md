# 文稿配音范围与继承模型验证（2026-10-26）

`packages/workbench/src/document-voices.ts` 直接读取和修改 `TeachingDocument.production`。范围使用文稿、页面、稳定步骤 ID 或明确选择的步骤 ID；批选去重后按原文稿顺序返回，不依赖运行快照的数值步骤绑定。继承顺序与 kernel 的 `resolvedVoice` 一致：本步、页面、文稿默认，均未设置时保持未设置。

页面或文稿设置默认保留下级覆盖，批选默认保留已有本步覆盖。显式替换才删除相应范围的下级 `voiceSource`；`null` 与 `undefined` 表示恢复继承，并遵循相同保护规则。单步直接设置或删除自己的配音来源。`none` 是显式静音，`recording` 保持原素材引用，二者都参与覆盖计数。

预览的 `updated`、`preserved`、`unchanged` 合计为范围内步骤数。`updated` 包括有效值或继承来源改变；`overrides` 独立统计现有配置槽位：文稿范围含页面和步骤槽位，页面范围含本页步骤槽位，单步或批选范围含所选步骤槽位。一个页面覆盖即使影响多个步骤，也只计一个页面槽位；被步骤覆盖遮挡的页面槽位仍计入配置数。

忽略目录中的 `.presmium/document-voices-proof.mjs` 使用两页、六个稳定步骤的最小真实文稿。它包含共享讲稿、发音与 cue、TTS／静音／真实本地音频素材的录音来源、三层制作设置、讲稿开始覆盖、cue 停顿和媒体片段。结果写入 `.presmium/ui-evidence/document-voices.json`，48 项检查全部通过。
