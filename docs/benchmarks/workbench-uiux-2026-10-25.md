# 工作台公共控件与作者流程：2026-10-25

本次在真实 Studio 和 Chromium 中操作文稿，没有新增或运行测试套件。原始示例只读检查；输入、断网与恢复在独立工作区副本中进行。性能数值是这些场景的观察值，不代表所有文稿达到架构中的 100 ms 目标。

## 已观察到的行为

| 场景 | 操作与结果 |
|---|---|
| 控件密度 | compact 单行输入／按钮 30px、13px 文字；regular 输入 36px；compact 讲稿最小高度 80px |
| 触屏 | 390px 视口、coarse pointer；工具与标签热区至少 44px，讲稿输入文字 16px |
| 正文保存 | 在副本输入三段不同文字，源码包含三段；切页与刷新后仍在 |
| 断网恢复 | 离线新增第四段，源码未更新而草稿已保留；恢复网络并刷新后显示恢复提示，重试写入原来源 |
| 文稿连续显示 | 原始冒泡排序 3 页、代码动画 8 页均可滚动与目录定位；冒泡排序开头、5 段过程和小结逐段匹配，代码动画各页正文前缀 8／8 匹配；窄屏选页后目录收起 |
| 生成内容 | 内容块显示画面、步骤与讲稿入口，没有实现源码切换按钮；原有教学代码仍正常显示 |
| 任意步骤 | GSAP 按 4、2、3、1 顺序定位，画面终态分别对应 5400、2400、3800、1200 ms |
| 讲稿写回 | 两次真实编译无诊断；显式讲稿的格式、标签与附加选项保留，播放时机可改为 after |
| 配音缓存 | 无引擎凭据读取冒泡排序 8 个真实缓存片段，缺失 0；修改后的缓存未命中文字形成当前字幕与静音占位，不生成音频 |
| 真实目录 | 未配置提供方返回 not-configured；火山适配器返回原有 6 个内置音色并标明 bundled，未调用外部合成 |

旧文稿曾被错误地只显示选中页面，现已恢复连续文稿。另发现旧文稿隐式讲解被正文筛选遗漏，已加入保留原步骤绑定的只读显示和讲稿修改入口；正文块模式仍只在内容画布编辑正文。这两项兼容检查必须同时核对源文字，不能只检查标题或页数。

## 性能与加载反馈

- 原始 4320 工作台的温缓存“打开＋定位末页”观察值为冒泡排序 631 ms、代码动画 831 ms，包含自动操作开销。
- 一次 GSAP 随机定位的选择延迟为 119／71／73／75 ms。不同画面还需等待教学动画完成，不能把动画播放时间算作切换等待，也不能由最好的一次推断全部低于 100 ms。
- 修改查看器源码后，一次冷缓存运行资源构建耗时 10098 ms。界面现区分准备预览与等待连接；准备请求 45 秒超时，收到地址后握手 15 秒超时，提供重试并保留诊断。
- 跳步先暂停现有播放器；修复暂停后残留动画帧继续推进的问题，没有建立第二个播放时钟。

浏览器记录覆盖 pageerror、控制台错误、HTTP 错误与请求失败。干净的原始文稿场景中上述错误均为零；切换文稿和取消订阅产生的 `net::ERR_ABORTED` 单独记录，不算连接失败。开发期间热替换曾出现启动顺序异常，因此最终结论使用新浏览器上下文重新检查。

## 验证边界

类型、分层、设计令牌、技能、包声明与差异检查按本次涉及范围执行。根项目声明动画包为验证文稿的开发依赖，使已有场景的类型解析使用真实公开包入口。未运行 `pnpm test`、`pnpm verify`、完整 e2e 或示例全量构建。
