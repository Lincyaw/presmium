# 工作台公共控件与作者流程：2026-10-25

本次在真实 Studio 和 Chromium 中操作文稿，没有新增或运行测试套件。原始示例只读检查；输入、断网与恢复在独立工作区副本中进行。性能数值是这些场景的观察值，不代表所有文稿达到架构中的 100 ms 目标。

## 已观察到的行为

| 场景 | 操作与结果 |
|---|---|
| 控件密度 | compact 单行输入／按钮 30px、13px 文字；regular 输入 36px；compact 讲稿最小高度 80px |
| 触屏 | 390px 视口、coarse pointer；工具与标签热区至少 44px，讲稿输入文字 16px |
| 正文保存 | 在副本输入三段不同文字，源码包含三段；切页与刷新后仍在 |
| 断网恢复 | 离线新增第四段，源码未更新而草稿已保留；恢复网络并刷新后显示恢复提示，重试写入原来源 |
| 文稿连续显示 | 原始冒泡排序 3 页、代码动画 8 页均可滚动与目录定位；冒泡排序开头、5 段过程和小结逐段匹配，代码动画各页正文前缀 8／8 匹配；窄屏选页后目录收起 |
| 生成内容 | 内容块显示画面、步骤与讲稿入口，没有实现源码切换按钮；原有教学代码仍正常显示 |

| 讲稿写回 | 两次真实编译无诊断；显式讲稿的格式、标签与附加选项保留，播放时机可改为 after |
| 配音缓存 | 无引擎凭据读取冒泡排序 8 个真实缓存片段，缺失 0；修改后的缓存未命中文字形成当前字幕与静音占位，不生成音频 |
| 真实目录 | 未配置提供方返回 not-configured；火山适配器返回原有 6 个内置音色并标明 bundled，未调用外部合成 |

旧文稿曾被错误地只显示选中页面，现已恢复连续文稿。另发现旧文稿隐式讲解被正文筛选遗漏，已加入保留原步骤绑定的只读显示和讲稿修改入口；正文块模式仍只在内容画布编辑正文。这两项兼容检查必须同时核对源文字，不能只检查标题或页数。

## 性能与加载反馈

- 原始 4320 工作台的温缓存“打开＋定位末页”观察值为冒泡排序 631 ms、代码动画 831 ms，包含自动操作开销。
- 一次 GSAP 随机定位的选择延迟为 119／71／73／75 ms。不同画面还需等待教学动画完成，不能把动画播放时间算作切换等待，也不能由最好的一次推断全部低于 100 ms。
- 修改查看器源码后，一次冷缓存运行资源构建耗时 10098 ms。界面现区分准备预览与等待连接；准备请求 45 秒超时，收到地址后握手 15 秒超时，提供重试并保留诊断。
- 跳步先暂停现有播放器；修复暂停后残留动画帧继续推进的问题，没有建立第二个播放时钟。

浏览器记录覆盖 pageerror、控制台错误、HTTP 错误与请求失败。干净的原始文稿场景中上述错误均为零；切换文稿和取消订阅产生的 `net::ERR_ABORTED` 单独记录，不算连接失败。开发期间热替换曾出现启动顺序异常，因此最终结论使用新浏览器上下文重新检查。

## 验证边界

类型、分层、设计令牌、技能、包声明与差异检查按本次涉及范围执行。根项目声明动画包为验证文稿的开发依赖，使已有场景的类型解析使用真实公开包入口。未运行 `pnpm test`、`pnpm verify`、完整 e2e 或示例全量构建。

本轮没有完成可搜索音色选择、音色继承和批量应用、显式配音生成的普通作者入口、媒体裁切／重新对齐、完整任务取消和导出前检查。IR 原生工程与 Tauri 也未开放。后续阶段继续按 RFC 的真实能力门槛实施。

## 后续实施：页面管理与运行反馈

同日的后续检查使用独立 Studio 工作区及全新 Chromium 上下文，未修改原始示例。页面更多菜单已接入重命名和同级移动；失败保留草稿，复制、删除及复杂来源操作仍未开放。运行反馈进入已有的诊断快照，不建立第二套诊断服务。

| 场景 | 实际结果 |
|---|---|
| 刚输入正文即重命名 | 正文先保存，再写页面标题；一次重命名确认耗时 236 ms，页面 ID、正文和讲稿均保留，焦点返回原页面操作按钮 |
| 重复标题与移动 | 移动后两个同名页仍保留各自 ID、正文和讲稿；撤消恢复顺序，之前保存的正文仍在 |
| 讲稿与播放时机 | 待保存的讲稿和 after 时机先确认，再重命名；正文和标题确认均通过 |
| 断网与恢复 | 页面标题草稿留在对话框；未保存正文留在浏览器，源码未被页面操作改写；恢复后正文保存成功，页数仍为 4 |
| 正文输入法等待 | 合成 compositionstart 且尚无正文事务时，重命名保持等待；compositionend 后才完成确认；这项检查不代表操作系统输入法的全平台验收 |
| 讲稿组字中断 | 关闭窗格后保留草稿与中断标记；重开和刷新均提示确认且不自动保存；页面操作在 341 ms 内拒绝并保留标题，明确保存讲稿后页面重命名成功，另一页讲稿未变；讲稿中断提示在四种显示组合均无溢出 |
| 隐藏源码与懒加载草稿 | 未采用的素材源码草稿阻止页面修改并原样保留；正文编辑器尚未挂载时恢复已有草稿，保存确认后才重命名 |
| 页面操作的四种显示组合 | 1440px／390px、浅色／深色无横向溢出；打开对话框聚焦输入，取消后返回原菜单按钮；触屏 390px 下输入高 44px、文字 16px |
| 前端与请求失败 | 在四种显示组合检查异常、HTTP 500、离线、超时、主动取消、去重、凭据隐藏、文稿切换和首页；清除当前工作台提示保留其他诊断来源 |
| 源码与编译能力 | 23 次定向真实编译覆盖中文 ID、重复标题、BOM、CRLF、Setext、Markdown 字面标题、1.4 万字符分块和字面标签；跨章、格式化标题、include、MyST 单元格及旧编译器能力均在写前拒绝 |
| 能力缓存 | 最小文稿在新服务中 36 ms 编译、0 诊断；相同能力的 ETag 返回 304，旧的仅 IR 修订标签返回 200 并携带实际编译器能力；能力不进入作者 metadata |

保存等待曾新增独立 SSE，实际浏览器中出现预览已更新而正文确认仍超时的失败。改为共用客户端的有界条件读取后，上述即时重命名通过，不再为每次保存增加长连接。协议的 `flush` 绑定原文稿、预览实例、代次与请求；重载不重播已发送的修改请求。

证据保存在本地 `.presmium/ui-evidence/`：`page-flow.json`、`page-script-flow.json`、`page-matrix.json`、`page-matrix-touch.json`、`runtime-verification.json`、`viewer-flush-final-verification.json`、`narration-ime-verification.json` 与 `page-capability-etag.json`，该目录不随仓库发布。未注入故障的最终浏览器场景没有前端异常；导航时主动取消的请求单独记录。未运行测试套件、全量示例构建或发布。
