起点为可信 `pointerdown`。可见光标同时核对真实原生焦点、目标节点和视口内坐标；两帧由 `requestAnimationFrame` 观察。首请求采用客户端请求事件时间；保存确认要求 actor 已保存、非 dirty／saving，版本已变，随后核对实际磁盘内容。四个阶段分别记录，不用保存时间代替输入响应，也不把请求已发出当作保存完成。

用户已接受这三个样本所示的新增页响应范围，后续优先功能闭环。该接受不包含保存耗时，不改变架构中的全局 100 ms 目标，也不由三个样本推导 P95。机器有 64 个逻辑 CPU，三个样本开始时的一分钟 loadavg 为 6.44、6.33、6.04；未设置浏览器 CPU 节流，仍是共享机器上的有限观测。光标区间内未观察到持续至少 50 ms 的 long task。
