A document is one web page with all its sections, as a static site shows a source file on one page. The sidebar lists the workspace's documents, grouped by each document's first tag in the workspace's order, with the current document's chapters under it; the page outline lists every section, the sections of a chapter indented; a section's title shows a `#` permalink when pointed at. The showcase theme drops its row of page buttons for the same two side columns. The pages earlier sites split a document into by chapter are built as redirects to the chapter's place on the document's page, and the dev server redirects them the same way.
