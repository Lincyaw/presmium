New projects install with pnpm 11 again: their `allowBuilds` matches the packages Presmium installs, including `protobufjs` from the speech engine. A project whose title is Chinese gets Chinese pages and README whatever the system language, and its first document's language follows; the README of every project kind explains how to edit, in the browser with Presmium Studio or with an AI coding tool.
