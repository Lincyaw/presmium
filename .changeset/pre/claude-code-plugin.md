Presmium is now a Claude Code plugin: `/plugin marketplace add Lincyaw/presmium` and `/plugin install presmium@presmium` bring the authoring, animation, SVG figure and plugin skills, the Presmium MCP tools (through `pnpm dlx @lincyaw/presmium mcp`) and the `/presmium:new`, `/presmium:studio` and `/presmium:export-svg` commands. New lecture, workspace and site projects also get the `presmium-figure` skill.
