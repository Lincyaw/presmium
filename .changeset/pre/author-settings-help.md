Settings in `presmium studio` show an author only what an author needs: language, appearance, font size, the coding view switch, keyboard shortcuts and Models. The coding view starts off and the AI's work details start compact, saved in the profile's own layer only for fields the author has not chosen, so later choices in Settings still apply. While the coding view is off, the permission mode, work details and their collapse timing, send behaviour while busy, and performance and usage stay hidden; the built-in plugins and agent presets pages are gone from the web carrier, so Harness's own presets are no longer selectable there. The Help dialog describes the current editor in the words of its buttons.
