Allow Markdown slide and only blocks to declare an absolute starting step and an exclusive ending step with at and until. Render changing results directly as Markdown with reversible replacement in the web presentation and Slidev, without a custom component or trace player.

Reading layout renders text, figures, tables and code in document order without presentation board wrappers. A document can also have a second native Markdown entry for a separately arranged, stepped slide deck.
