Scenes get more of each library and stay right when seeked. `d3Scene` draws a D3 graphic as a function of the time. GSAP scenes get the registered `plugins` (SplitText, DrawSVG, MorphSVG, MotionPath, Text, CustomEase, CustomBounce, CustomWiggle, Physics2D, PhysicsProps, Flip) and Three.js scenes the `addons` (CSS2DRenderer, Line2, ParametricGeometry, RoundedBoxGeometry, ConvexGeometry), which a lecture cannot import itself. `color()` returns `rgb()` for every token, including those written with `color-mix()`. A scene is built again when the theme changes, and when its size changes if it has no `resize`; its stage is a size container. Anime.js and GSAP scenes look the same at a time however it was reached (GSAP keeps 2D transforms), a section labelled `(gsap)=` no longer breaks GSAP's plugins, and Motion scenes draw transforms, SVG and CSS variables on the seek instead of on the next frame. New lectures, and the AI of presmium studio, get the presmium-animate skill.
