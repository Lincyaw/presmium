(classroom)=
## 课堂互动

:::{hints}
slides: { routeAlias: classroom }
:::

课堂互动建立在课堂会话之上：测验、练习、提问与理解度投票都写成 MyST 指令，在网页与幻灯片中都能用；导出为 notebook 时，测验成为题目列表，练习成为含起始代码与校验用例的代码单元格。

:::{slide}
- **测验** `{quiz}`：主讲开放与关闭，实时统计，每人只计最后一次作答
- **练习** `{exercise}`：提交后运行校验用例，标出典型错误
- **提问** `{question-box}`：问题挂在所在章节，主讲按位置查看
- **理解度** `{pulse}`：主讲视图显示分布
- **笔记**：网页中每个章节与带标签的块旁都可以记笔记，只有自己能看到
:::

没有加入课堂时，测验是自测，练习照样校验，笔记保存在本地浏览器。加入课堂后，作答、提交、提问与投票汇总到主讲的“互动”面板（网页导航栏中的“互动”按钮，幻灯片演讲者视图的 Presmium 面板）。课堂结束后不再接受写入；主讲可以归档课堂，课堂记录写入文稿目录下的 `.presmium/classroom/`。

(classroom-quiz)=
## 课堂测验

```{quiz}
BPE 每一轮合并的是哪一对相邻符号？

- [ ] 文本中最先出现的一对
- [x] 出现次数最多的一对
- [ ] 出现次数最少的一对
```

主讲点“开放作答”后，学习者选择并提交；重复提交会替换之前的答案，统计只计每人最后一次作答。主讲点“关闭作答”后不再接受作答，所有人看到统计与正确答案。

(classroom-exercise)=
## 练习校验

````{exercise} python
写函数 `mean(xs)`：返回列表 `xs` 的平均值；空列表返回 `0`。

```python
def mean(xs):
    return sum(xs) / len(xs)
```

```python
assert mean([1, 2, 3]) == 2, "mean([1, 2, 3]) 应为 2"
assert mean([]) == 0, "空列表应返回 0"
```
````

起始代码在空列表上会除以零。提交后，每条校验用例单独运行，失败的用例标出典型错误（这里是“除以零”）与排查提示。代码由浏览器中的 Python 执行，不需要服务器。
