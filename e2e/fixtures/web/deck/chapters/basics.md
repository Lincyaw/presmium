(scrolly)=
## 滚动叙事

:::{hints}
web: { layout: scrolly }
:::

:::{slide}
:reveal: items
- 编译：源码编译为 IR
- 渲染：IR 运行时按章节渲染
- 发布：VitePress 外壳生成静态站点
:::

上屏内容固定在一侧，讲解在另一侧滚动，步骤随滚动推进。第一步，编译源码。

第二步，渲染章节。

第三步，发布站点。

:::{component} FixtureStepper
:span: 2
steps: [离线缓存, 形态互跳]
:::

步进组件接在列表之后出现，再占用两步。

先是离线缓存：网页加载一次之后，断网也能阅读与搜索。

然后是形态互跳：每个章节都能在幻灯片中打开，停在当前步骤。
