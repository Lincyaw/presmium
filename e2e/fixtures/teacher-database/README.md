# 教师数据库场景

私有回归文稿，验证教师动态讲解 Python 代码的完整路径；不作为第二个公开示例。

从仓库根目录运行 `pnpm exec playwright test e2e/teacher-database.spec.ts --project chromium --workers 1`。测试先把文稿复制到已安装依赖的私有工作目录，再用真实 CLI 检查并构建网页、幻灯片与 notebook；只构建本份文稿。

现场按“内存 → 日志 → 共享会话 → 预测 → 逐行查询 → 删除 → 文件恢复 → 学生练习”讲解。代码块按文稿顺序运行；重置后从初始化块重新运行。预测页再次运行会增加日志条数，这是有意保留的真实状态。

测试在复制后的文稿目录初始化独立 Git 仓库，因此 `code-ref` 从它自己的仓库根目录引用 `code/database.py`。编辑副本的 Python 文件会真实更新副本预览；不读取原仓库里的同名文件。新增源文件无已提交版本，代码演进使用可逆的 `at` / `until` 替换；无需为了演示创建或修改 Git 历史。
