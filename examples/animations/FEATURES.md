# 功能与示例章节

运行 `pnpm studio` 后，在工作台文稿列表打开所需导览，再按页面名定位；阅读站点则从“功能导览”菜单进入。文稿链接指向唯一的 `lecture.json`，便于查看或复用实际内容。已有工作台副本不会被自动覆盖；查看仓库中的最新示例可使用 `pnpm studio examples/animations`。

[机器可读索引](features.json) 同时登记插件、公开组件和动画实现的覆盖关系。外部服务、硬件、凭据和浏览器权限需要单独准备；“按条件启用”不表示已经配置。

## 先动手：编辑你自己的方案

[功能导览 09：动手编辑一份讲义](guide-authoring/lecture.json)使用每人 30 元的午餐预算材料。先复制“午餐预算”页，把配菜价格由 8 改为 10，再核对合计 27、余额 3；接着编辑两步讲稿、调整时机并刷新重开。它使用真实的页面、嵌套正文、表格、步骤、共享讲稿、发音与 cue，没有另造编辑器或假按钮。

| 你要尝试的动作 | 练习页 | 前提 |
|---|---|---|
| 新建页面并继续输入 | 从“先完成一个真实的小练习”开始 (`start`) | 工作台文档编辑入口 |
| 复制、重命名、上下移动与安全删除 | 复制材料，做一个可比较的方案 (`copy`) | 工作台页面栏；复制后可先撤消再恢复 |
| 纯文字页的两步讲稿、发音、cue 与正文连续保存 | 纯文字页也能编辑本步字幕与讲稿 (`scripts`) | 顶部“本步字幕 / 讲稿”旁栏；动画也可就地编辑 |
| 混合时机、真实继承来源与恢复 | 看清来源，再调整本步播放时机 (`timing`) | 页面继承初始为 1200 / 250 毫秒，不需要语音服务 |
| 未采用的毫秒草稿与放映门禁 | 看清来源，再调整本步播放时机 (`timing`) | 改为有效值或明确恢复继承后再放映 |
| 批注、原生撤消、源事务历史、保存与恢复 | 用批注说明修改，用历史核对结果 (`comments`) | 工作台原生选区；保存失败时先核对草稿 |
| 已保存版本的放映与输出 | 保存你的方案，再进入放映或输出 (`delivery`) | 实际编译与所需输出工具可用；未准备的配音不会生成 |

此轮补充与既有八份导览的验证范围分别记录在[作者练习验证](../../docs/benchmarks/feature-authoring-supplement-2026-10-26.md)与[既有导览验证](../../docs/benchmarks/feature-guides-2026-10-26.md)，条件能力不等于已配置或已验证成功。

## 已明确的能力门槛

- 示例中的稳定步骤和组件公开按钮可直接操作。七份导览现为 22 个定义声明实际公开参数，包括计数文字、场景数值、媒体显示与课堂问题；实现路径、交互目标及子块标识不作为可改参数。没有作者参数的组件仍保留无公开字段状态。参数表单与共享素材入口的运行时能力以 [UI/UX RFC](../../docs/rfc-workbench-uiux.md) 为准；本次 schema 补充不宣称独立实现副本已经可用，见步骤导览的 `semantic` 一节与[验证记录](../../docs/benchmarks/component-properties-design-schemas-2026-10-28.md)。

- 视频制作已有独立入口、当前页三轨时间线、真实缓存波形、共享播放器和精确播放头；编排时间来自同一份保存版本的真实计划。可按讲稿导览的 `timeline` 页使用已有课程缓存操作，或按 `silent` 页新建简单静音文稿；缺缓存时显示估计时长，未知时序不能伪装为可播放。已有独立英文文件通过真实服务完成转写、采用讲稿、新配音与播放；当前环境仍需实际配置服务，不代表所有语言或提供方都已验收。

- 静音没有真实词语时码；本导览保留句子中间动作 cue，因此整份导览的按时播放会明确报告编排问题。不要把能读、能切稳定步骤与可按毫秒播放混为一谈。请用 `silent` 页的新建文稿练习，不移动原 cue 来掩盖此门槛。

- 当前编译器明确拒绝 module 实现；使用项目 file 或已注册 plugin。 见 [guide-publishing](guide-publishing/lecture.json) 的 `extension` 一节。
- hub 认证仍保留但未实现；示例不提供成功连接按钮。 见 [guide-environments](guide-environments/lecture.json) 的 `jupyter` 一节。
- 本地音频片段已可在确认步骤时段内裁切和混音，原音可明确采用为整段本步旁白；视频、旁白裁切、跨步连续分配和无真实对齐的内部提示仍有门槛。见 [guide-production](guide-production/lecture.json) 的 `recording` 与 `media-editing` 两节。

当前索引保留既有 95 项及 12 项作者与播放流程，再补充 5 项制作时间线练习与 1 项原音采用流程，共 113 项；16 个官方插件、18 个官方插件教学组件入口与 7 种动画适配器逐项有真实文稿落点。IDE、MCP、打包与发布工具在“发布与协作”中提供操作指引。
