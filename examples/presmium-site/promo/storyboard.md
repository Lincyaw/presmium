# Presmium 60 秒产品宣传片：v4 制作稿

主张：**Presmium 帮老师把训练过程组织成可逐步讲清、可回看的讲解。**

观众是准备机器学习课程的老师和内容作者。影片从一件具体工作开始：讲“学习率为什么可能让训练越学越差”。前后始终是这堂课、同一组公式与训练内容，以及老师组织讲解的过程。首页恢复原有结构，本次只制作和接入影片。

看完后，观众应能说出老师在 Presmium 里做了什么，以及学习者最后可以怎样使用这堂课。中央证明帧是真实产品里的操作与结果：老师选择一个已编排步骤，相关教学内容获得焦点，预测与损失显示同一次更新；回到先前步骤能恢复相应状态。

## 叙事与范围

采用“痛点 → 老师使用产品组织讲解 → 实际教学过程 → 回看与课后使用 → 行动”的单一任务。公式、代码和图形都是这堂课的内容，不由抽象雕塑代替。参考 Apple 的剪辑、景别、停留与文字克制，镜头始终服务操作、因果与结果。

屏幕录制使用真实的本地 Presmium 工作台与公开阅读／放映页面，选择、编辑、预览与放映无需配置模型。不存在的“一键把公式变动画”“点击自动连接代码”“任意学习率滑杆”不进入镜头。动画属于预先真实写入文稿的教学内容；实际代码高亮是教学内容特写，不宣传成产品自动理解或连接源码的操作。

全片无旁白，没有烧录讲稿，也不显示“同一份文稿”“示例数据”或制作原理说明。必要的课程标题、公式、代码、学习率和界面标签保留，广告文案一次至多一行。详细数学推导、数据来源和适用条件在配套小课中。

## 动作与剪辑

- **保留同一任务。** 课程问题、公式、代码与五个训练点在前后镜头中保持可辨认。分散材料进入产品是剪辑对位，不伪装成一个不存在的自动导入操作。
- **原因先发生。** 老师的真实步骤选择先落下，再突出对应教学内容，最后显示变化结果。一次只有一个主要焦点，光标停到一旁后才读结果。
- **界面内推近。** 先展示真实应用全貌，再对所选页面、步骤或教学结果做受控推近；不连续环绕数学图形。切换用途时使用相同课程内容对位。
- **解释具体过程。** 动画可以连接公式关键项、教学代码和图形，但不把这种电影引导效果说成 Presmium 的自动连线能力。实际应用界面不能为了广告临时画出新按钮、参数或成功状态。
- **结果有时间。** 大步长、低步长和回看的结果各自停稳；最后五秒保持品牌与行动。数据与参数不能使用弹簧过冲或为了节奏变更数值。

## 真实教学内容

课程继续使用 `scenes/model.ts` 的线性回归计算。五个无噪声观测来自 `y = 3x`，输入平方均值为 1，因此 `L(w) = 0.5(w − 3)²`；这是本课的数据尺度，不推广成所有线性回归的损失公式。

两组从 `w = −1`、`L = 8` 开始。学习率 2.2 三次更新的参数为 `7.8、−2.76、9.912`，损失依次升高。学习率 0.35 的第二次为 `w = 1.31`，第八次约为 `w = 2.87254、L = 0.00812`。回看恢复这两个实际状态。参数 1.6 仍可收敛，因此不把“更小总是更快”作为结论。

数学值来自内容的真实计算，不制造训练速度、学习提升、备课节省或用户满意度指标。影片展示可观察的操作和结果，不编造学生评价，也不将 AI 评阅或脚本中的学生角色当作真人学习实验。

## 权威文稿与声音

`lecture.json` 是内容与时序入口，八个 `full` Sections 各有一个 scene 块和一个步骤。八个场景定义均引用 `scenes/product-film.ts`，通过 `parameters.shot` 选择 `pain、author、arrange、overshoot、focus、revisit、outputs、brand`；每个定义只有 `show` 状态和对应单段时长。公共 SceneView 默认采用 16/9 画幅。

全片无 narration，默认 `voiceSource: none`，`trailingPauseMs: 0`。当前沿用现有 60 秒原创 WAV，通过八个连续媒体片段引用 `[0,6]、[6,14]、[14,23]、[23,33]、[33,42]、[42,48]、[48,54]、[54,60]` 秒区间。没有改动音乐生成源码，也不宣称配乐已按新分镜重写；带声音复核时检查它与实际操作、转折和落定的配合。

## 验收顺序

1. 先看八张真实过程的静音 rest-frame 连排：能否读出材料割裂、老师组织讲解、教学比较、回看与课后使用；不能只读出数学图形在动。
2. 看真实 UI 操作与内容特写：产品在前五秒出现，操作能在实际工作台找到，没有虚构功能或 AI 自动生成的假演示。
3. 看完整连续动画：每次点击／选择先于结果，镜头让关键步骤更清楚，不以长时间特写代替过程。
4. 检查最终压缩影片、音乐、确切 60 秒时长、回退恢复、网页播放和受管素材。数学正确、构建成功和分辨率达标不代替产品叙事验收。
5. 记录实际查看的帧、连续样段与成片，不把 AI 复核写成真人冷观众测试，不编造学生理解率。
