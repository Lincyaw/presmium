# 《Make complex things clear》分镜

影片是英文的，约 61 秒，配乐是 Kevin MacLeod 的 “Newer Wave”。看完后，观众知道：在 Presmium 里圈出文稿的一段、说一句要什么，AI 就把动画加进来；同一份文稿现场能一步一步讲，会后能当网站看、能导出视频发出去。影片用一堂课做例子，论文报告、技术分享、产品发布也是同样的做法；片尾把这个例子收到更大的承诺上。这是一支带产品演示的宣传片。

故事是一个闭环：学生深夜提了一个问题，老师上节课在黑板上画了三遍没讲明白；这次换个讲法；第二天上课一步一步讲，课后学生自己说出了答案。问题和答案都在同一个课程群里。

## 写法

- 一次只出现一句话，放在画面下方同一个位置，字号不小于画面宽度的 2.95%（1080p 下 56 px）；要读的字渲染后不小于 32 px。句子短，用口语，不用 empower、unlock、seamless 这类空话。
- 产品画面都是英文界面的真实采集：工作台的拖选、批注框（每三个字符一帧）、AI 助手与预览步骤，放映版的九个步骤，课程网站，导出的教学视频逐步帧。被编辑的课是 `learn/lecture.json` 的英文译文。AI 的修改是重放：采集时把加好动画的文稿按 AI 修改的格式写入版本历史，工作台显示的是它真实的样子。
- 故事场景（夜晚的房间、黑板、教室、手机聊天）是统一风格的扁平插画：设计令牌中的影片配色（`film-*`），圆角、无描边、一盏台灯的暖光。聊天界面是插画，不模仿任何真实聊天软件。
- 原因先于结果：指针按下，界面才变；翻页笔按下，幻灯片才走一步；点 ✕，播放器才收起。
- 衔接用同一张图表：推进时镜头不越出笔记本屏幕，两边以相同的取景交叠不超过 0.25 秒，再拉开。每段的衔接写在 `film.ts` 的 `carries`，由 `film-kit.ts` 的 `playChain` 实现：每段画面在自己的图层里，有自己的镜头与时间线。
- 每个结果至少停 0.5 秒，“Oh, I see!” 之后约 2.5 秒完全静止，片尾静止 3 秒以上。

## 声音

- 音乐：“Newer Wave”，Kevin MacLeod（incompetech.com），Creative Commons: By Attribution 4.0（http://creativecommons.org/licenses/by/4.0/）。截取原曲 30.57 秒起的 61.09 秒：前 6.5 秒是律动，随后安静的段落垫在工作台下，24.0 秒起是铺垫，26.18 秒重拍，动画就在这一拍出现；最后 0.3 秒淡出，停在第 28 小节线上。
- 按键声来自 Kenney 的 Interface Sounds（CC0），一类动作一个声音、一个音量：工作台里每一次鼠标点击（批注按钮、保存、AI Assistant、输入框、发送、预览的三个步骤）、翻页笔的每一下、手机上的两次轻触（按住进度条、点 ✕）。切镜、镜头移动、打字、滚动没有声音。
- `pnpm score` 混音并调到约 −16 LUFS、真峰值不超过 −1.5 dBTP；配乐按步骤切成片段挂在各步骤上。
