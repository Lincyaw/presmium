# 功能合集与教程

示例分为两类：**功能合集**逐页演示单项功能；**教程**按编号步骤介绍工作台中的操作。运行 `pnpm studio` 后可在文稿列表中打开；发布的网站中，可通过首页的“示例”进入示例库。

依赖网络、本机 Docker、WebGPU 或外部服务的页面，均在页内注明前提。机器可读的功能清单见 [features.json](features.json)。

## 功能合集

### [内容与排版](showcase-content/lecture.json)

正文支持的各类内容：文字与公式、列表、表格、分栏、Mermaid 与 PlantUML、思维导图、音视频、图片、提示与折叠、在线媒体。

- **文字与版式**
  - 文字与公式
  - 列表与引用
  - 表格
  - 分栏与选项卡
- **图表**
  - Mermaid 图表
  - PlantUML 图表
  - 思维导图
- **媒体**
  - 音频与视频
  - 图片与动图
  - 在线音视频与图片
  - YouTube 视频
- **语义标记**
  - 提示、折叠与术语
  - 卡片与同步选项卡

### [步骤与动画](showcase-steps/lecture.json)

以步骤组织画面：逐项揭示、继承上一步、动画状态与参数、D3 数据绑定、交互组件、光标与聚光提示。

- **步骤**
  - 逐项揭示
  - 继承上一步
- **动画**
  - 动画状态与参数
  - D3 数据绑定
  - 更多动画库
- **交互**
  - 交互组件
  - 光标与聚光提示

### [代码与运行](showcase-code/lecture.json)

代码引用与按步高亮，浏览器内运行 JavaScript 与 Python，以及 Docker、WASI、WebGPU、Jupyter 等运行环境。

- **展示代码**
  - 按步骤高亮
  - 代码变体
  - 引用项目文件
- **浏览器内运行**
  - JavaScript 与参数
  - Python
  - 逐行执行
  - 共享会话
  - 错误与超时
- **更多运行环境**
  - Docker 容器
  - C、C++、Ruby 与 SQLite
  - WebGPU 计算着色器
  - jax-js 张量
  - Python 调用 WebGPU
  - 远端 Jupyter
  - 远端终端

### [课堂互动](showcase-classroom/lecture.json)

测验、预测、代码练习、提问与理解度投票、阅读笔记、跟随主讲，以及教师版与学生版输出。

  - 单选与多选

  - 代码练习
  - 阅读笔记
- **课堂**
  - 提问与理解度投票
  - 跟随主讲
  - 教师版与学生版

### [阅读与发布](showcase-publishing/lecture.json)

搜索与脚注、放映与演讲者视图、按媒介输出、网页组件、高对比度、译文、AI 问答与导出。

## 教程

### [编辑一份讲义](tutorial-editing/lecture.json)

以“午餐预算”为材料，依次练习复制页面、编辑讲稿、调整播放时机、批注与版本历史、放映与导出。

- **开始之前**
  - 练习材料：午餐预算
- **复制页面并修改**
- **编辑每一步的讲稿**
- **调整播放时机**
- **批注、撤消与历史**
- **放映与导出**

### [讲稿与配音](tutorial-narration/lecture.json)

依次练习读音与动作标记、播放时机、时间线预览、静音讲授、AI 配音、录音、音频片段与视频导出。

- **开始之前**
- **讲稿**
  - 讲稿里的读音、动作与停顿
  - 随动画讲，还是动画后讲
- **预览**
  - 在时间线上预览
  - 做一份静音讲授
- **配音**
  - 选择音色，生成配音
  - 用自己的声音录音
  - 加入音频片段
- **导出视频**
