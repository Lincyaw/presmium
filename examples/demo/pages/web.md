## 网页形态

网页是主媒介：IR 运行时在浏览器中直接渲染每个章节，VitePress 提供导航、侧栏、大纲、深色模式与搜索界面。讲稿即正文，讲解段落按原顺序显示为正文，读者不看幻灯片也能读懂这一节。

:::{slide}
- 侧边目录、页内大纲、上一节与下一节
- 全文搜索覆盖标题、讲解、上屏内容与代码
- 幻灯片与网页一键互跳，停在对应位置
:::

```ts
// 网页渲染端：IR 运行时按视图渲染同一份 IR
const viewer = createViewer(doc)
viewer.setView('present')
```

搜索框支持中文分词，断网后也能检索。导航栏的视图菜单在文档、滚动叙事与放映之间切换，当前章节与步骤保持不变。

:::{only} web
网页中才有的补充说明：切换视图不需要重新构建，同一份 IR 在浏览器中换一种方式呈现。
:::

:::{only} slides
幻灯片中才有的提示：按导航栏的文档按钮在网页中阅读本节。
:::

## 滚动叙事

:::{hints}
web: { layout: scrolly }
:::

:::{slide}
:reveal: items
- 编译：源码编译为 IR
- 渲染：IR 运行时按章节渲染
- 发布：VitePress 外壳生成静态站点
:::

滚动叙事式的章节：上屏内容固定在一侧，讲解在另一侧滚动，步骤随滚动推进。第一步，编译源码。

第二步，渲染章节。IR 运行时直接从 IR 渲染，不生成 Markdown。

第三步，发布站点。搜索索引在构建时从 IR 文本生成，随网页一起发布。

:::{component} PmDemoStepper
:span: 2
steps: [离线缓存, 形态互跳]
:::

步进组件接在列表之后出现，再占用两步。

先是离线缓存：网页加载一次之后，断网也能阅读与搜索。

然后是形态互跳：每个章节都能在幻灯片中打开，停在当前步骤。
