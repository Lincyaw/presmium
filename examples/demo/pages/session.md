## 课堂会话

:::{hints}
slides: { routeAlias: session }
:::

课堂会话把主讲与学习者连到同一个课堂：主讲创建课堂，学习者打开加入链接或扫描二维码进入，各自看到同一份文稿。课堂状态显示在网页导航栏的“课堂”按钮中，幻灯片形态显示在演讲者视图的 Presmium 面板中。

:::{slide}
- **创建课堂**：主讲填写昵称后创建，得到加入链接与二维码
- **加入课堂**：学习者打开链接 `?room=<课堂>&name=<昵称>`，或扫码后填写昵称
- **结束课堂**：主讲结束后，学习者看到课堂已结束
:::

课堂服务由 `presmium-classroom-server` 提供，地址写在文稿 frontmatter 的 `presmium.session.server` 中，例如 `ws://localhost:1234`。没有配置课堂服务时，文稿照常放映与阅读，课堂按钮显示“未连接”。

```sh
pnpm exec presmium-classroom-server --port 1234
```

## 跟随与自主

:::{slide}
:reveal:
**跟随主讲**：主讲翻到哪一节、哪一步、哪个视图，学习者就到哪里
:::

学习者加入课堂后默认跟随主讲：主讲的章节、步骤与视图实时共享，网页形态通过宿主的导航接口移动 IR 运行时，幻灯片形态还同步 Slidev 的状态，例如圈画标注。

:::{slide}
:reveal:
**自主浏览**：学习者随时切换，自己翻阅前后内容
:::

想回头看前面的内容时，学习者点“自主浏览”，主讲继续翻页也不会把他拉走。

:::{slide}
:reveal:
**回到主讲进度**：一键回到主讲当前的位置，并恢复跟随
:::

点“回到主讲进度”，立即回到主讲所在的章节与步骤，之后继续跟随。
