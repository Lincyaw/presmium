# ChainPrune：先合并等价步骤，再选择短轨迹

## A 简报与论点
面向了解CoT和SFT的研究者，约3—4分钟。看完后明白：训练轨迹的效率要同时看词数和推理步骤，跨路径合并语义等价节点，再按两个维度选择偏好样本，可以学到更紧凑的推理。
论文 arXiv2608.21860v1，2026-08-22，Weihang Pan等。ABT：词数减少仍可能步骤冗余；把不同路径的等价状态合并，才有机会缩短结构，再把这种偏好写入训练。

## B 参考作品操作
第一期hint.ts沿同一题保留参考解答、逐步显露词，再映射到比较；本篇沿2+3×6同一算例，追踪两个等价节点合成共享节点，保留结果端点。原图镜头先全局流程后聚焦合并、选择、训练三处，保持原图空间。只读参考源时间线，动态视觉相似度仍需协调者审阅。

## C 术语与配色
蓝色：原始路径节点；红色：等价待合并节点/被拒绝轨迹；绿色：合并保留节点/优选轨迹；黄色：当前检查；不同任务间不改角色。推理步骤是按语义划分的中间过程；token是模型生成的词元，两者不是一回事。语义等价先在具体的两种18表达中展示再命名。DPO首次说明为学习优选/拒绝样本的相对偏好；NLL解释为继续直接学习优选答案的监督项。Pareto原则用“两个维度都更省”先展示，再命名。
