# 论文分享第二期：Re-Search

今天分享得克萨斯农工大学和约翰斯·霍普金斯大学的论文 Re-Search。

本研究让6个大模型通过最多100次是非问答，重新找回200篇论文的核心想法，并用提问树观察它们如何探索。结果发现，模型会钻得太深或频繁换方向；提供外部候选问题，能帮助部分模型找到更有效的线索，但收益因模型而异。
