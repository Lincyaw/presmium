# AI问了100次，为何还找不到答案

给大模型100次是非问答的机会，它能找回一篇论文的核心想法吗？

Re-Search记录了6个模型在200篇ICML 2026方法论文上的提问过程。沿着提问树，可以看到三种搜索方式：钻得太深、换方向太勤，以及沿有效线索深入并适时回退。

补充候选问题能改变结果：GPT-OSS在第30问的恢复分数，从独自提问的4.16提高到外部候选中自行挑选的5.20；随机选择外部问题为4.43。收益有模型条件：GPT-5.4接入共享问题池后反而下降0.59。

恢复分数是三个模型评审对“当前猜测接近论文方法的程度”的1—10分均值。本实验考察找回已有想法，真实科研中的有效性仍需验证。
