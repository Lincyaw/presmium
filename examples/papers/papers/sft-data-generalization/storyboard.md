## B. 论点与主线
看完后，观众知道数据条件会改变SFT与RL的泛化比较，因为看到了同一题从一条解答到匹配训练轨迹后，差距收窄，再观察到更多方法被覆盖。
ABT：RL常有更好的迁移表现，但原先按题匹配不等于按训练轨迹匹配，因此应同时控制来源和轨迹量。
内部比较三条主线：课堂练习册（直观但易拟人化）、预算尺（直指比较口径）、方法地图（适合机制解释但开场较抽象）。采用预算尺，以同一道题和解题轨迹贯穿；后半段方法地图解释可能机制。

## D. 术语
| 名称 | 首次定义 | 不混同 |
|---|---|---|
| SFT / 监督微调 | 给定解答的逐步监督 | 只背最终答案 |
| RL / 强化学习 | 生成解答，用结果奖励更新 | 特定数据来源 |
| 轨迹 | 从问题到最终答案的完整过程 | 题目数量、API调用次数 |
| 泛化 | 数学训练后，12项其他推理任务迁移 | 单个任务正确率、所有领域 |
| 覆盖 | 方法至少出现100次 | 出现过一次 |
| 长尾方法 | 频率排名末20%的方法 | 所有138种方法 |
| 评测标准误 | 评测集不确定性 | 训练种子波动 |

## E. 数据依据与边界
主文Qwen2.5-7B；附录Qwen3-8B-Base。通用推理为12项指标归一化到0–100的均值。39,623正确+98,641最终答案错误=138,264；不拿17,391×8重算总样本。budget原图橙柱38.7/39.9/42.7/43.7；RL43.8。总量匹配混合90/10：44.4±0.42；RL43.8±0.43，非训练种子区间。Qwen3-8B最佳50/50，42.6与42.5。覆盖原图101/119/128/132是总方法覆盖；LLM识别138类。tail对照40→108为正确轨迹内方法使用计数，可多标签，不是答对题数。数据仍来自已有RL模型；训练轨迹/梯度预算匹配不等于端到端成本相等。
