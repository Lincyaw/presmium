# 分词速览

:::{slide}

(glance-tokens)=
## 词元是什么

:::{slide}
**文本** → 词元 → 编号 → 模型
:::

语言模型只会处理数字。分词器先把文本切成一个个小块，叫作词元；再查词表，把每个词元换成编号。模型读的是这串编号，写出的也是编号，分词器再把它们换回文字。

同一个词元在不同的词里编号相同。比如 `lowest` 和 `newest` 都以 `est` 结尾，两个词里的 `est` 是同一个词元，模型因此能看出它们有相同的结尾。

(glance-bpe)=
## BPE 怎样得到词元

:::{slide}
1. 从字节开始：每个字节是一个词元
2. 数一数每一对相邻的词元出现了几次
3. 把最常见的一对合并成一个新词元
4. 重复，直到词表够大
:::

BPE 从字节出发，反复把最常见的一对相邻词元合并成一个新词元，并按先后记下每一次合并。合并几次由我们决定：合并得越多，词表越大，常见的词越可能整个成为一个词元。
